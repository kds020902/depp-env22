## 어떻게 모았나

1. **검색 엔진 이미지 검색은 쓰지 못했다.** 이 컨테이너에서 검색 결과를 자동으로 가져오는 동작이 막혀 있다. Wikimedia Commons API는 요청 제한(HTTP 429)이 풀리지 않았다.
   그래서 iNaturalist 공개 API만 썼다. "sweet potato mold" 같은 검색어로 찾은 관찰(약 50건)과 고구마(*Ipomoea batatas*) 관찰 전체를 받았다.
2. 사진 목록 23,736장 → 작은 미리보기를 받아 초록색이 많은 사진(잎·밭)을 덜어 7,617장.
3. CLIP으로 "고구마 덩이가 찍힌 사진"일 가능성을 매겨 888장으로 줄였다. **무엇을 볼지 고르는 데만 썼고 라벨로 쓰지 않았다.** TV-13의 답은 보지 않았다.
4. 888장을 모두 눈으로 보고 라벨을 붙였다. 비정상으로 붙인 94장은 큰 사진으로 한 번 더 봤다.
5. 큰 사진의 CLIP 특징으로 기존 자료와 견줘 0.95 이상 닮은 32장을 뺐다: T3~T9, 기본 데이터셋, 두 번째 분류기의 학습 행, 개발 세트, 임시 폴더 사진 227장. T9와 0.95 이상인 것은 없었다(최대 0.90).

## 알아둘 점

- **곰팡이 사진이 적다(27장).** iNaturalist는 자연 관찰 사이트라 썩은 고구마 사진이 드물다. 그중 13장은 곰팡이를 확대한 사진이라 고구마 모양이 보이지 않는다.
  같은 관찰을 여러 각도로 찍은 사진이 있어, 서로 다른 고구마로 세면 더 적다.
- 비정상의 3분의 2가 싹이다. 싹을 틔우려고 물에 꽂아 둔 사진이 많다.
- 라벨은 150픽셀 미리보기로 붙였다(비정상은 250픽셀로 다시 확인). 정상 208장은 큰 사진으로 다시 보지 않았다.
- 한 사람이 붙인 라벨이다. 두 번째 사람의 확인은 없다.
- 곰팡이·썩음 사진은 Codex가 사용자 컴퓨터에서 이미지 검색으로 따로 모으기로 했다(지시문은 사용자에게 전달).
