# 흙 묻은 당근·쪼그라든 오이 오답 고치기 (채택 안 함)

[more_data](../more_data/README.md) 실험의 새 시험지 160장에서 두 가지 오답이 나왔다.

- **(a) 흙 묻은 정상 당근을 상함으로 봄:** 학습 데이터를 늘린 모델(G42)이 흙 묻은 정상 당근 20장 중 11장을 상함으로 봤다.
- **(b) 갈색으로 쪼그라든 상한 오이를 상한 감자로 봄:** 현재 모델(B)과 G42 모두 그랬다.

이 둘을 고치려고 두 후보를 학습했다. 미리 정한 기준을 넘지 못해 `model.pth`는 그대로 두었다. Test는 채점하지 않았다.

## 원인 확인

틀린 사진마다, 모델이 보는 특징이 가장 비슷한 학습 사진 5장을 찾았다.

- **(a) 당근:** 틀린 11장의 이웃 55장 중 54장이 more_data에서 넣은 "상한 당근" 휴대폰 사진(vegetables-quality-dataset-2)이었다. 다시 보니 이 사진들 상당수는 썩지 않고 마르거나 표면이 거칠기만 했다.
- **(b) 오이:** 틀린 사진의 이웃은 상한 감자와 상한 피망이었다. 학습 데이터에는 갈색으로 쪼그라든 상한 오이가 한 장도 없다.

## 바꾼 것 (Train에만)

1. **상한 당근 다시 보기:** more_data에서 넣은 상한 당근 100장을 더 엄격한 기준으로 다시 봤다. 검게 썩음, 곰팡이, 무름, 구멍 같은 부패가 분명한 43장만 남기고 57장을 뺐다. 마르거나 거칠기만 한 사진, 흙이 대부분인 사진, 글씨가 들어간 사진, 파스닙은 뺐다. 기록은 `carrot_rotten_rereview.json`에 있다.
2. **보강 사진 54장:**
    - 흙 묻은 정상 당근 30장 (Flickr·Wikimedia)
    - 부패가 분명한 상한 당근 웹 사진 19장 (Kaggle "Fresh and Spoiled Food")
    - 갈색으로 쪼그라든 상한 오이 5장 (Kaggle 두 곳, FruitQ, Wikimedia)
    - 목록은 `added_photos.csv`에 있다.
3. **오이 사진은 찾을 수 있는 만큼 다 찾았다.** 데이터셋 4곳과 인터넷을 다 뒤져도 갈색으로 쪼그라든 상한 오이는 6장뿐이었다. 그중 1장은 기존 데이터의 Test 사진과 같아서 뺐다.
4. **마지막 중복 검사:** 보강 사진 65장 중 11장이 기존 데이터의 복사본이라 뺐다(Train 8장, Test 2장, Valid 1장).

| 후보 | Train |
|---|---|
| H | 3차 1,260장 + 보강 54장 = 1,314장 |
| Gp | more_data 2,146장 − 거친 상한 당근 57장 + 보강 54장 = 2,143장 |

## 확인용 사진 (학습 전에 고정)

- **흙 묻은 정상 당근 27장 (`carrot_check.csv`):**
    - 새 시험지에 쓰지 않은 Mendeley 정상 당근 13장
    - 인터넷에서 찾은 흙 묻은 당근 중 학습에 쓰지 않은 14장. 같은 사람이 올린 사진은 한쪽에만 넣었다.
- **갈색 상한 오이 10장:** 새로 모을 사진이 없어서, 문제를 발견한 새 시험지의 10장을 그대로 썼다. 같은 사진이라 결과가 실제보다 좋게 나올 수 있다.
- **새 시험지 160장:** 오답을 보고 고친 것이라 이제는 개발용이다. 다른 클래스가 나빠지지 않았는지 보는 데 썼다.
- Valid 300장, 인터넷 사진 221장도 함께 봤다.

## 무엇을 배웠나

- **(a) 당근은 원인을 고치면 나아진다.** 흙 묻은 정상 당근 확인 사진에서 H는 26장, Gp7은 27장을 맞혔다(B 23장, G42 14장).
    - Gp의 새 시험지 정상 당근도 G보다 나아졌다(9·15 → 12·17). 하지만 B(20장)에는 못 미쳤다.
    - 거친 상한 당근을 빼도 같은 출처의 거친 정상·상한 사진이 남아 있어, 완전히 고쳐지지는 않은 것으로 보인다.
- **당근을 고치자 감자에 반대 문제가 생겼다.** H는 새 시험지에서 상한 감자 4~5장을 정상으로 봤다(B 1장). 흙 묻은 정상 당근을 넣어 "흙 묻은 갈색 표면 = 정상"을 배운 것으로 보인다. 한 클래스의 지름길을 막으면 비슷하게 생긴 다른 클래스로 지름길이 옮겨 갈 수 있다.
- **(b) 쪼그라든 오이는 고치지 못했다.**
    - 보강 사진 5장으로는 부족했다. 오히려 Gp는 10장 중 하나도 오이로 맞히지 못했다.
    - 이 정도로 썩은 오이는 사람이 봐도 오이인지 알기 어렵다. 그래도 "상함" 판정은 모든 모델이 10장 모두 맞혔다.
    - 고치려면 썩어 가는 오이를 직접 찍은 사진이 수십 장 필요하다. 공개 데이터에는 거의 없다.
