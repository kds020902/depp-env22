# 살짝 상한 토마토: 조각으로 한 번 더 보기 (C1, 반영 안 함)

계획, 개발 결과, 사용자 결정: [PREREG.md](PREREG.md).

- **방법:** 답이 "정상 토마토"일 때만 사진을 5조각(네 모서리 + 가운데, 2/3 크기)으로 자른다.
    - 어느 조각이라도 CLIP 분류기의 "상한 토마토" 몫이 t 이상이면 답을 "상한 토마토"로 바꾼다.
    - 코드: `src/decision.py`의 `apply_crop_check`. 체크포인트에 `tomato_crop_check`가 있을 때만 쓴다.
- **개발 사진 (T3+T4+T5, [dev_results.json](dev_results.json)):**
    - 상한 토마토 16 → 24/28 (57% → 86%, t 0.9)
    - 정상 토마토 47 → 44/49
    - 새 오경보 3장은 모두 밭에서 줄기에 달린 덜 익은 토마토였다.
    - 미리 정한 오경보 규칙으로는 탈락했다. 사용자가 결과를 본 뒤 "밭 토마토는 빼고, T6로 확인"을 골랐다(t 0.9).
- **블라인드 테스트셋 T6([기록](../../results/t6_test/README.md)):** 대파 없앰(G1)과 합친 G1C1로 한 번 채점했다.
    - 상한 토마토는 TV-12도 이미 22/22를 맞혀서 늘 수 없었다(조건 +3 ❌). 이 22장 중 21장은 많이 썩은 데이터셋 사진이다.
    - 정상 토마토 20장에서는 오경보가 늘지 않았다(19 → 19).
    - 조각 검사로 바뀐 답은 0장이다. 탈락한 다른 조건(거르기 −4)은 대파 없앰 때문이다.
- **블라인드 테스트셋 T7([기록](../../results/t7_test/README.md)):** 사용자 결정으로 줄기에서 딴 실제 장면 토마토 46장을 새로 모아 C1만 한 번 채점했다.
    - 바뀐 답은 0장이다. TV-12가 이미 상한 토마토 28/32(88%, "살짝" 10/12)를 맞혔다.
    - TV-12가 정상으로 답한 "살짝" 상한 토마토 2장도 조각의 상함 몫이 0.9를 넘지 못했다.
- **판정:** 반영하지 않는다.
    - 개발 사진에서 보인 효과(57% → 86%)는 대부분 밭에서 줄기에 달린 토마토에서 나왔다.
    - 줄기에서 딴 실제 토마토에서는 TV-12가 이미 잘 맞혀서, 블라인드 시험지 두 개(T6, T7)에서 바뀐 답이 없었다.
