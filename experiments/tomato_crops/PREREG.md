# 살짝 상한 토마토: 조각으로 한 번 더 보기 (결과를 보기 전에 적음, 2026-11-03)

## 왜
- [root_and_tomato](../root_and_tomato/README.md)에서 상한 토마토 사진을 152장까지 더해도 개발 사진의 상한 토마토는 16 → 17/28이었다.
    - 사진을 더하는 방법으로는 거의 움직이지 않았다.
- 사용자 결정(2026-11-03): "3번(다른 방법)"을 해 본다.

## 방법 (후보 C1)
- 시스템의 마지막 답이 **"정상 토마토"일 때만** 사진을 조각 5개로 잘라 다시 본다.
    - 조각: 네 모서리와 가운데, 가로·세로 2/3 크기
- 조각마다 CLIP 분류기(TV-12의 다섯 채소 분류기)로 상한 토마토 몫을 본다: P(상한 토마토) / (P(정상 토마토) + P(상한 토마토)).
- 한 조각이라도 이 몫이 **t 이상**이면 답을 "상한 토마토"로 바꾼다.
- **바꾸지 않는 것:** 다른 채소의 답, 상함 → 정상, 거르기, 채소 모델, 분류기 가중치
- **예전과 다른 점:**
    - [improve_without_photos](../improve_without_photos/README.md) 3번은 같은 조각 검사를 다섯 채소 모두에 썼다.
    - 그때는 흙 묻은 당근·감자·밭 채소의 무늬를 상함으로 보아 실패했다.
    - 이번에는 껍질이 매끈한 토마토에만 쓴다. 밭 사진(160장)은 사용자 결정으로 기준에서 뺀다.
- **이미 알고 있는 것 (새 증거가 아님):** 예전 기록에서 인터넷 221장의 토마토는 아래처럼 바뀌었다.
    - t 0.9: 상한 토마토 30 → 35/45, 정상 토마토 47 → 46/49
    - t 0.8: 정상 토마토 45/49
    - 이 사진들은 지금 Flickr·Wikimedia 차단으로 다시 받을 수 없다. 그래서 인터넷 221장 조건은 그 기록(같은 TV-12, 같은 조각)으로 잰다.

## t 고르기 (규칙)
- **후보:** t = 0.6, 0.7, 0.8, 0.9
- **"정상 토마토 → 상한" 오경보:** T3·T4·T5의 정상 토마토 49장과 Valid 정상 토마토 30장, 합계 79장에서 센다. 오경보가 **2장 이하**인 가장 작은 t를 고른다.
    - 2장 이하인 t가 없으면 C1은 "효과 없음"이다.

## 개발 확인 기준 (고른 t, TV-12 대비)

| 볼 것 | 기준 |
|---|---|
| **상한 토마토 맞힘** (T3+T4+T5, 28장) | **+3장 이상** (16 → 19 이상) |
| 정상 토마토 맞힘 (T3+T4+T5 49장) | −2장 이내 |
| Valid 300 맞게 남김 | −3 이내 |
| 인터넷 221 맞게 남김 (예전 기록) | −3 이내 |
| 다른 채소의 답 | 바뀌지 않음 (설계상, 확인만) |

## 블라인드 테스트셋 T6 (한 번만)
- **채점할 후보:** 개발 확인을 통과한 것을 합친 마지막 후보다.
    - C1과 [대파 없애기 G1](../no_greenonion/PREREG.md)이 둘 다 통과하면 G1 + C1을 함께 채점한다.
    - 하나만 통과하면 그것만 채점한다.
- **채점 방법:**
    - [`results/t6_test/score.py`](../../results/t6_test/score.py)에 조각 검사를 넣는 부분만 더한다. 정답·세는 방법은 바꾸지 않는다.
    - 이 수정은 T6 채점 전에 커밋한다.
- **T6의 대파 사진 1장:**
    - G1에서는 이 사진의 맞는 답이 "거름"으로 바뀐다. 그래서 새 채소 비교에서 빼고 따로 적는다.
    - 이 사진은 Flickr 차단으로 아직 받지 못했다. 끝내 받지 못하면 T6를 174장으로 채점한다. 빠진 1장은 두 모델 모두에서 똑같이 뺀다.
- **채택을 제안하는 조건 (TV-12 대비, 모두 만족):**

| 볼 것 (T6) | 조건 |
|---|---|
| 상한 토마토 22장 맞힘 | +3장 이상 (C1이 들어 있을 때) |
| 정상 토마토 20장 맞힘 | −1장 이내 |
| 다섯 채소 맞게 남김 | TV-12 − (정상 토마토에서 잃은 수) 이상. 상한 토마토에서 얻은 만큼 늘어야 한다. |
| 걸러야 할 사진 75장 거름 | −3장 이내 |
| 양파 2장 종류 맞힘 | −1장 이내 |

- **판정:** 조건을 모두 지키면 TV-13 반영을 제안한다. 반영은 사용자가 정한다.
- T6는 이 한 번만 쓰고, 결과를 보고 무엇을 고치지 않는다.
- 상한 토마토 22장 중 21장은 데이터셋 사진(흰 배경)이다. 그래서 실제 장면에 대한 증거로는 약하다. 결과에도 그렇게 적는다.

## 개발 결과 (2026-11-03, [dev_results.json](dev_results.json))

    - TV-12도 이미 3장을 틀린다. 이 3장을 세는 문구는 규칙 설계의 허점이었다.
    - 새로 생긴 오경보만 세어도 가장 적은 t 0.9가 3장이다. 어느 쪽으로 읽어도 탈락이다.
