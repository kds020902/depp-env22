# 약점 3: 채소 모델을 320 픽셀로 다시 학습 (효과 없음, 반영 안 함)

계획: [PREREG.md](PREREG.md). 결과: [dev_results.json](dev_results.json). 같은 학습 사진과 설정으로 입력 해상도만 224 → 320 픽셀로 올렸다. seed는 42였다(Valid 손실 0.322, seed 43은 0.343).

| 항목 (개발 몫 + T3 + T4) | TV-12 | P1 | H (320) | HP (320 + P1) |
|---|---:|---:|---:|---:|
| **상한 토마토 맞힘 (42장)** | 55% | 60% | 52% | 52% |
| 정상 토마토 맞힘 (42장) | 93% | 93% | 95% | 98% |
| 멀쩡한 감자 맞힘 (60장) | 58% | 73% | 63% | 75% |
| 상한 감자 맞힘 (36장) | 86% | 86% | 67% | 67% |
| 개발 사진 718장 맞게 남김 | 91.2% | 91.5% | 91.6% | 91.4% |
| 자신 있게 틀린 답 (바깥, 판단 보류 0.9) | 3.7% | 3.1% | 6.1% | 5.6% |
| 상함 → 정상 (바깥, 답한 것) | 7 | 7 | 12 | 10 |
| 채소 모델 처리 시간 (CPU, 1장) | 40 ms | 40 ms | 56 ms | 56 ms |

- **결과:** 기준(상한 토마토 +5장)에 못 미쳤다. H는 −1, HP는 P1 대비 −3이었다. 지키는 조건 8개는 지켰다.
- **해석(추측):** 학습한 상한 토마토 126장은 대부분 많이 썩은 사진이다. 그래서 세세하게 보게 해도 "작은 반점 = 상함"을 배울 사진이 없다.
    - 오히려 "멀쩡해 보이면 정상"을 더 확신하게 되어 상한 감자와 상함 → 정상 오류가 나빠졌다.
    - 막힌 곳은 해상도가 아니라 학습 사진으로 본다.
- τ는 같은 규칙으로 다시 골랐다(H 0.7, HP 0.8).
