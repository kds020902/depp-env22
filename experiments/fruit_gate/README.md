# 과일 판별 모델을 앞에 따로 두기 (1·2·3차 모두 채택 안 함)

[fruit_other](../fruit_other/README.md)에서 과일을 11번째 클래스로 학습하자 과일은 잘 걸렀지만, 채소 점수가 떨어졌다. 그래서 이번에는 채소 모델(`model.pth`)은 그대로 두고, 그 앞에 "과일인지 채소인지"만 가리는 작은 모델(문지기)을 따로 두었다.

- **과일이 거의 확실하면:** "학습된 데이터가 아닙니다"로 답한다.
- **그 밖의 사진:** 지금처럼 채소 모델이 답한다. 채소 모델의 energy 점수 검사도 그대로 한다.

채소 모델을 다시 학습하지 않으므로, 채소 종류·상태를 맞히는 점수 자체는 바뀌지 않는다. 바뀔 수 있는 것은 문지기가 채소를 과일로 잘못 보고 돌려보내는 수뿐이다.

미리 정한 기준을 넘지 못해 채택하지 않았다. `model.pth`는 그대로이고 Test는 채점하지 않았다.

## 문지기 모델

- **구조:** MobileNetV3-Small이다(ImageNet으로 미리 학습, 파라미터 250만 개, 약 10MB). 채소 모델(EfficientNet-B0)보다 작다. 계산량으로 보면 판별 시간이 약 15% 늘어난다.
- **학습 방법:** `fruit_gate.py`
    - 2개 클래스(채소/과일)로 미세조정했다.
    - 입력 크기와 증강은 채소 모델과 같다.
    - 채소 사진이 훨씬 많아서 클래스별 가중치를 줬다.
- **학습 사진:**
    - **채소 2,783장:**
        - 3차 Train 1,260장
        - 예전 실험에서 검수해 둔 886장([more_data](../more_data/README.md))과 325장([fix_carrot_cucumber](../fix_carrot_cucumber/README.md) K)
        - kritikseth 데이터의 다섯 채소 웹 사진 312장(`kritikseth_vegetables.csv`). 과일 사진 일부와 같은 데이터라서 "웹 사진이면 과일"로 배우지 않게 넣었다.
    - **과일 671장:** fruit_other의 과일 후보(Kaggle 세 곳, CC0)에서 Valid 30장을 뺀 나머지다. 살구·체리 등 5종은 이번에도 넣지 않았다.
    - **Valid:** 채소 300장과 과일 30장이다.
    - **복사본 제외:** 확인용 사진(Valid·Test 채소, 인터넷 채소·과일, 160장 시험지, 아시아 오이, 흙 당근 등)과 같은 사진은 모두 뺐다. kritikseth 채소 사진 174장이 여기에 걸렸다.
- **"과일" 기준값:** Valid 채소 300장 중 돌려보내는 사진이 1%(3장) 이하가 되도록 Valid만 보고 정했다. 시드 42는 0.80, 시드 7은 0.85였다.

## 무엇을 배웠나

- **채소 점수는 거의 지켰다.**
    - 160장 시험지는 그대로(142장)였다.
    - Valid는 3장씩만 돌려보냈다. 미리 정한 1% 기준대로다.
    - 11번째 클래스로 학습했을 때(fruit_other)는 160장 시험지가 129·130장으로 떨어졌다. 이번 방식이 훨씬 안전하다.
- **과일 거르기는 11번째 클래스 방식보다 약했다.**
    - 인터넷 과일을 77% 걸렀다. fruit_other는 88%였다.
    - 채소를 지키려고 기준값을 높게(0.80~0.85) 잡은 탓이 크다.
    - 과일 학습 사진도 671장뿐이고, 과일 한 종류당 수십 장이다.
- **감은 여전히 절반 이상 통과한다.** 23장 중 10~11장만 걸렀다. 학습한 감 사진이 Fruits-262의 12장뿐이었다.
- **문지기가 과일로 잘못 본 채소:**
    - 인터넷 채소에서는 주로 정상 토마토·감자다(7~11장).
    - 시드 42는 아시아 오이 5장도 과일로 봤다. 가늘고 긴 초록 오이가 학습한 채소 사진에 거의 없기 때문으로 보인다.

## 2차 시도: 과일 사진을 크게 늘리기 (v2, 채택 안 함)

1차의 가장 큰 원인을 과일 학습 사진 부족(671장, 종류당 십여 장)으로 보고, 학습 사진만 바꿨다. 모델, 학습 방법, 기준값 정하는 규칙, 확인용 사진, 채택 기준은 1차와 같다(`PREREG_v2.md`).

**더 넣은 사진 (Train에만, `added_photos_v2.csv`)**

- **과일 1,996장:** Fruits-262에서 과일 34종마다 최대 60장씩 더 받았다.
    - 감·귤(mandarine)·동양배(yali pear)·대추·유자·금귤도 들어 있다.
    - 살구·체리 등 5종은 이번에도 넣지 않았다.
- **채소 364장:**
    - Fruits-262의 토마토와 피망 224장. 과일과 같은 데이터에서 넣어 "이 데이터 사진이면 과일"로 배우지 않게 했다. 1차 문지기가 과일로 잘못 본 채소는 주로 토마토였다.
    - 동아시아 오이 140장([asian_cucumber](../asian_cucumber/README.md) J2에서 쓴 사진)
- **확인 방법:** 종류마다 6장씩 뽑아 눈으로 확인했다. 한 장씩 다 보지는 않았다.
- **복사본 제외:** 확인용 사진과 같은 사진 10장, 1차 사진과 같은 사진 16장, 서로 같은 사진 46장을 뺐다.
- **학습 사진:** 채소 3,147장, 과일 2,667장이 됐다(1차: 2,783장, 671장).

    - 인터넷 과일은 77%에서 85%로 올랐다.
    - 감도 23장 중 10~11장에서 14~16장으로 늘었다.
    - 문지기가 과일과 채소를 더 확실히 가르게 되어 기준값이 0.80~0.85에서 0.65~0.69로 내려갔다. Valid 채소 300장 중 돌려보내는 수는 그대로 3장이다.
- **160장 시험지와 Valid는 1차와 같았다.** 채소 모델을 건드리지 않는 방식이라 채소 점수가 안정적이다.
- **남은 문제는 인터넷 채소 사진이다.**
    - 문지기가 10~15장을 과일로 봤다. 주로 정상 토마토, 감자다.
    - 그중 원래 채소 모델이 맞게 답하던 사진은 4~5장이다. 나머지는 원래도 energy 검사에 걸렸거나 틀리던 사진이다.
    - 이 때문에 기준(270장)에 3장 모자랐다.
- **동아시아 오이 연구용 사진(검은 배경)은 도움이 되지 않았다.** 아시아 오이 37장 중 5~6장을 여전히 과일로 봤다. 실제 환경에서 찍은 아시아 오이 사진이 필요하다.

## 3차 시도: 실제 장면 사진 더하기 (v3, 채택 안 함)

2차에서 문지기가 과일로 잘못 본 인터넷 채소는 주로 시장·밭·부엌에서 찍은 토마토·감자였다. 문지기의 채소 학습 사진은 대부분 깨끗한 배경의 채소 하나였다. 그래서 실제 장면 사진을 더했다. 학습 사진 말고는 1·2차와 같다(`PREREG_v3.md`).

**더 넣은 사진 (Train에만, `added_photos_v3.csv`)**

- **출처:** [LVIS fruits-and-vegetables](https://www.kaggle.com/datasets/henningheyen/lvis-fruits-and-vegetables-dataset)(MIT)에서 잘라낸 사진이다. 부엌·시장·식탁을 찍은 COCO 사진이다.
- **채소 192장:**
    - 잘라낸 700장을 모두 눈으로 보고, 익히지 않은 채소만 남겼다. 당근 106장, 토마토 40장, 피망 16장, 오이 15장, 감자 15장이다.
    - 대부분은 피자·샐러드·구운 요리 속 채소라서 뺐다.
    - LVIS에 "토마토"로 잘못 표시된 감·오렌지도 뺐다.
- **과일 192장:** 같은 수를 넣었다. 채소 쪽에만 실제 장면을 넣으면 "실제 장면 = 채소"로 배울 수 있어서다. 사람·음식·채소가 찍힌 17장은 뺐다.
- **복사본 검사:** 잘라내기 전의 원래 사진이 확인용 사진(일상 사진 400장 포함)과 같은지 검사했다. 걸린 사진은 없었다.

**무엇을 배웠나**

- **결과는 2차와 거의 같았다.** 인터넷 채소 맞게 남긴 수 합이 2차와 같은 267장으로, 기준에 3장 모자랐다.
- **시드에 따라 결과가 크게 달랐다.**
    - 시드 42는 인터넷 채소를 7장만 과일로 봐서 B보다 2장 적은 136장을 남겼다.
    - 시드 7은 19장을 과일로 봤다.
    - 실제 장면 사진 192장은 전체 6,198장 중 3%라서 효과가 작고 흔들렸다.
- **같은 확인용 사진으로 세 번 시도했다.**
    - 더 시도하면 확인용 사진에 맞춰 고르는 셈이 된다.
    - 문지기를 더 고치려면, 이번 확인용 사진을 쓰지 않은 새 인터넷 채소·과일 사진으로 평가해야 한다.

## 다시 돌리기

```bash
python experiments/fruit_gate/fruit_gate.py train --train gate_train.csv --val gate_val.csv --out runs/G42 --seed 42
python experiments/fruit_gate/fruit_gate.py score --model runs/G42/gate.pth photo.jpg
```

`gate_train.csv`·`gate_val.csv`는 사진 경로와 정답(0 채소, 1 과일)을 담은 표다. 사진은 위 실험들의 `added_photos.csv`와 `kritikseth_vegetables.csv`로 다시 모은다.
