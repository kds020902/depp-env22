# CLIP 분류기 학습 사진 균형 맞추기: 계획 (결과를 보기 전에 적음, 2026-11-02)

## 사용자 요청

- "과하게 상한" 채소 사진을 걸러 낸다.
- 정상 / 비정상 사진을 1:1로 맞춘다. 종류마다 최소 350장으로 한다.
- 모자란 것은 가진 데이터에서 찾고, 없으면 인터넷에서 모은다.

**사용자가 정한 것:**
- 과하게 상한 기준: 형체가 무너진 것만
- 범위: 다섯 채소 10칸
- 모자랄 때: 정상도 같은 수로 맞춘다 (변형 복사는 쓰지 않음)
- 적용: CLIP 분류기만 (채소 모델은 그대로)

## 1. 과하게 상한 사진 빼기 (끝남)

- CLIP 글 설명("알아볼 수 없게 녹아내린", "전체가 곰팡이로 덮인" 대 "상한 곳이 있는", "조금 상한")으로 상한 학습 사진 1,520장에 순위를 매겼다.
- 위에서부터 288장을 눈으로 보고, 나머지에서 무작위 48장을 더 봤다.
- 형체가 무너진 사진 78장을 뺀다.

| 종류 | 뺀 장 수 |
|---|---:|
| 오이 | 62 |
| 감자 | 7 |
| 피망 | 5 |
| 당근 | 2 |
| 토마토 | 1 |

- 무작위 48장 중 1장이 해당했다. 그래서 보지 않은 나머지 약 1,200장 중 약 25장이 더 있을 것으로 본다(추정).

## 2. 목표 장 수

- 종류마다 목표 T = max(350, 정상·비정상 중 적은 쪽)으로 한다. 정상과 비정상을 둘 다 T장으로 맞춘다.
- 많은 쪽은 무작위로(seed 42) 줄인다. 오이 정상은 아시아 오이와 서양 오이 비율을 유지한다.
- 모자란 쪽은 다음 순서로 채운다.
    1. 이미 검수한 학습 몫 사진(experiments/t3_weak_spots의 학습 몫)
    2. 작업 폴더의 예전 데이터셋(Kaggle 2개)에서 아직 안 쓴 사진. 눈으로 검수한다.
    3. 인터넷(iNaturalist·Wikimedia Commons). 눈으로 검수한다.
- 끝까지 모자라면 그 종류는 찾은 만큼으로 정하고, 정상도 같은 수로 줄인다.
- **같은 사진 막기:** 새로 넣는 사진은 다음과 CLIP 코사인 0.95 이상이면 넣지 않는다.
    - 지금 학습 사진
    - 모든 평가 사진: Valid, Test, 첫 인터넷 221, 160장, 아시아 오이, 새 인터넷 241, 아무 사진, 새 채소 테스트셋, T3, T4, 약점 개발용
