## L1의 T3·T4 채점 (한 번, 참고) ([t3_t4_reference.json](t3_t4_reference.json))

- T4는 이미 한 번 채점했고, T3는 반별 결과를 진단에 썼다. 그래서 둘 다 블라인드가 아니다. 계획에 T4를 블라인드라고 적은 것은 잘못이었고, 채점 전에 바로잡았다.
- 같은 과정으로 TV-12를 다시 돌리면 저장된 답과 0장 다르다.

| 항목 | TV-12 | L1 |
|---|---:|---:|
| 다섯 채소 맞게 남김: T3 137 + T4 63 | 109 + 41 = **150** | 110 + 44 = **154** |
| 상함 → 정상 (61장 중) | 17 | 14 |
| 정상 → 상함 (139장 중) | 25 | 23 |
| 새 채소 종류 (47장) | 36 | 42 |
| 걸러야 할 사진 거름 (100장) | 60 | 77 |

- 미리 정한 규칙(150 이상, 17 이하)을 지켰다.
- 다섯 채소 차이(+4/200)는 우연과 구분하기 어렵다. 확실히 오른 곳은 거르기(+17)와 새 채소(+6)다.
- Test 300(참고)에서는 판단 보류를 켰을 때 자신 있게 틀린 답이 3장에서 7장으로 늘었다.

## 결정 (사용자, 2026-11-03)
- **지금은 반영하지 않는다.** `model.pth`와 `predict.py`는 TV-12 그대로다.
- 새 블라인드 테스트셋 **T5**를 만들어 L1을 다시 확인한 뒤 정한다.
- **L1을 쓸 때의 비용:**
    - 모델 파일이 약 3.4GB다(지금 0.6GB).
    - CPU에서 사진 한 장에 약 0.7초가 걸린다(추정).
    - 웹 데모(브라우저)에는 넣을 수 없다.
