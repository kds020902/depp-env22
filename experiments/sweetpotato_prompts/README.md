# 감자·고구마 글 설명(CLIP 텍스트) 비교: 반영 안 함

- **결론:** 문구만 바꿔서는 달라지지 않는다. 세 후보 모두 미리 정한 조건(상한 고구마 +2장)에 못 미쳤다.
- 계획은 [`PREREG.md`](PREREG.md)에 결과보다 먼저 적었다(커밋 `ef422fb`). 문구는 [`prompts.json`](prompts.json), 결과는 `dev_results.json`이다.
- 가중치와 판정 기준은 모두 TV-12 그대로다. `model.pth`는 바뀌지 않았다.

## 결과 (개발 사진만, 블라인드 시험지는 읽지 않음)

| 본 것 | TV-12 | P0 이름만 | P1 사진 문맥 | P2 보이는 특징 |
|---|---:|---:|---:|---:|
| 상한 고구마 25장 → 고구마로 답함 | 21 (84%) | 20 (80%) | 19 (76%) | 22 (88%) |
| 상한 고구마 25장 → 상한 고구마로 답함 | 18 (72%) | 17 (68%) | 16 (64%) | 19 (76%) |
| 상한 고구마 25장 → 감자로 답함 | 3 | 3 | 3 | 2 |
| 정상 고구마 63장 → 고구마로 답함 | 54 (86%) | 54 | 54 | 54 |
| 감자 259장 → 고구마로 답함 | 2 (0.8%) | 2 | 2 | 2 |
| 상함 → 정상 오류 (상한 사진 385장, 같은 채소의 정상) | 17 | 17 | 17 | 17 |
| 〃 어느 채소든 정상으로 답함 (정정, PREREG 덧붙임 1) | 17 | 17 | 17 | 17 |
| 〃 그중 답을 낸 사진(판단 보류 제외) | 8 | 8 | 8 | 8 |
| 다섯 채소 맞은 수 (827장) | 745 | 745 | 745 | 745 |
| 판단 보류 (969장) | 165 (17.0%) | 170 (17.5%) | 166 (17.1%) | 165 (17.0%) |
| 답을 낸 사진의 정확도 | 747/779 (95.9%) | 742/774 (95.9%) | 745/778 (95.8%) | 748/779 (96.0%) |
| 과일 374장 거름 / 일상 400장 거름 | 347 / 400 | 347 / 400 | 347 / 400 | 347 / 400 |
| TV-12와 답이 달라진 사진 (1,935장 중) | – | 1 | 2 | 2 |

- **조건:** 상한 고구마를 고구마로 답한 수가 +2장 이상이어야 한다. P2가 +1장, P0가 −1장, P1이 −2장이다. 나머지 조건은 세 후보 모두 만족했다.
- 한 장이 4%포인트라서 ±1~2장은 우연과 구분되지 않는다.
- **정정 (PREREG 덧붙임 2):** 상한 고구마 25장 중 3장은 TV-12 학습 사진과 거의 같은 사진이었다. 이 3장을 빼면 22장 중 TV-12 19, P0 18, P1 17, P2 20장이다. 차이와 결론은 같다.
- TV-12의 문구를 같은 코드로 다시 넣으면 저장된 임베딩이 그대로 나온다(코사인 0.999 이상). 비교 코드가 TV-12와 같은 방식으로 글을 넣는다는 뜻이다.

## 왜 안 바뀌나: T8 오류가 나는 단계 (TV-12만 봄, 후보는 T8에 대 보지 않았다)

T8의 깨끗한 상한 고구마 16장을 단계별로 나눠 봤다.

| 단계 | 결과 (16장) |
|---|---|
| 다섯 채소 시스템이 거른 사진 | 0장. 모두 "상한 감자"로 답했고 13장은 확률 0.9 이상이다 |
| 두 번째 분류기(학습 가중치 + 글 0.25배)가 고구마를 1순위로 본 사진 | 3장 |
| 그중 학습 가중치만 보면 | 2장 |
| **글 설명 점수만 보면** | **12장** |
| 새 채소 확률이 0.8 이상(답을 바꾸는 기준) | 0장 (중앙값 0.09, 최대 0.73) |

- **읽는 법:** 글 설명은 지금 문구로도 16장 중 12장을 고구마로 본다. 문제는 문구가 아니다. 글 점수가 0.25배만 더해져서, 사진으로 학습한 가중치(44장으로 배운 상한 고구마)가 낸 "감자"를 뒤집지 못한다.
- 개발 사진의 상한 고구마 25장에서는 같은 분류기가 24장을 고구마 1순위로 본다. 즉 개발 사진은 학습 사진과 닮았고, T8 사진은 닮지 않았다.

## 다음에 해 볼 것 (추측, 아직 확인하지 않음)
- **상한 고구마 학습 사진을 늘린다.** 교수님 피드백의 방향과 같다. T8과 닮은 웹 사진이 필요하다.
- 글 점수의 비중(α 0.25)이나 전환 기준(0.8)을 바꾸는 것은 변수가 다른 별도 실험이다. V4-R 때 새 분류기를 먼저 믿었다가 기존 채소 11장을 새 채소로 보낸 일이 있어서, 감자 오인을 함께 봐야 한다.
- 어느 쪽이든 **T8로 고르지 않는다.** 새 블라인드 시험지가 필요하다.

|---|---:|---|
| 상한 고구마 (학습·개발용) | 60장 이상 | 지금 학습 44장, 개발 25장 |
| 상한 고구마 (새 블라인드 시험지용, 위와 다른 출처) | 30장 이상 | 한 장이 3%포인트 이하가 되도록 |
| 상한 감자·흙 묻은 정상 감자 (새 시험지용) | 각 30장 | 감자를 고구마로 잘못 보는지 확인 |

- 사진 규칙은 [`results/t8_test/PHOTO_GUIDE.md`](../../results/t8_test/PHOTO_GUIDE.md)와 같다. 학습용과 시험용은 출처(사이트·올린 사람)가 겹치지 않게 나눈다.
