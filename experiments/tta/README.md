# 뒤집기 평균(TTA) 확인 (채택 안 함)

사진을 원본, 좌우 뒤집기, 상하 뒤집기, 둘 다 뒤집기의 4장으로 만들어 예측을 평균 내 봤다. 다시 학습하지 않고 예측 방법만 바꾸는 방법이다. 미리 정한 기준(`PREREG.md`)을 넘지 못해 쓰지 않았다. Test는 채점하지 않았다.

## 한 일

- 비교 기준은 지금 시스템이다. 채소 모델과 CLIP 분류기를 합친 것이고, TTA는 없다.
- 후보는 두 가지였다.
    - **T1:** 채소 모델만 4장 평균을 낸다.
    - **T2:** 채소 모델과 CLIP 분류기를 모두 4장 평균 낸다.
- 평균을 낸 뒤 온도와 "학습된 데이터가 아닙니다" 기준은 지금과 같은 규칙으로 다시 맞췄다.
- 둘 중에서는 Valid 교차 엔트로피가 더 낮은 T1이 골라졌다. NLL은 T1 0.0989, T2 0.1074였다.

**판정:** 채택하지 않았다. 오히려 인터넷 채소 사진에서 5장 줄었다.

## 무엇을 배웠나

- **채소 모델만 쓸 때는 Valid가 조금 올랐다(281 → 284).** 하지만 CLIP 분류기를 합친 지금 시스템에서는 Valid가 1장만 늘었다.
- **인터넷 사진에서는 오히려 나빠졌다.** 뒤집은 사진은 학습 사진과 같은 분위기에서만 도움이 되고, 다른 분위기의 사진에서는 채소 모델의 실수를 평균으로 굳히는 경우가 있었다.
- **두 모델을 합친 것이 이미 비슷한 효과를 낸다.** 서로 다른 모델의 판단을 합치는 것이 같은 모델에 뒤집은 사진을 여러 번 보여 주는 것보다 효과가 컸다.
- 예측 시간을 늘릴 이유가 없으므로 `predict.py`와 데모는 그대로 둔다.
