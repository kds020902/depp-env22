# 뒤집기 평균(TTA), 확인용 사진을 보기 전에 적음 (2026-10-27)

## 무엇을 하나

- 사진 한 장을 원본, 좌우 뒤집기, 상하 뒤집기, 둘 다 뒤집기의 4장으로 만들어 각각 예측하고 평균 낸다(test-time augmentation).
- 학습 때도 좌우·상하 뒤집기를 썼으므로, 뒤집은 사진은 모델에게 낯설지 않다.
- 다시 학습하지 않는다. 바뀌는 것은 예측하는 방법뿐이다.

## 이미 본 것

- 채소 모델(B)만으로 Valid를 봤을 때, 원본 281장에서 4장 평균 284장이 되었다(Valid NLL 0.200 → 0.192).
- 그 밖의 확인용 사진과 Test는 TTA로 보지 않았다.

## 비교 기준: 지금 시스템

지금 `model.pth`, 즉 채소 모델 + CLIP 분류기이고 TTA는 없다.

| | 정확도 | 맞게 남긴 수 |
|---|---:|---:|
| Valid 300장 | 288 | 285 |
| 인터넷 채소 221장 | 190 | 173 |
| 160장 시험지 | 150 | 145 |
| 아시아 오이 37장 | 32 | 31 |
| 인터넷 과일 374장 중 거른 수 | – | 244 |
| 일상 사진 400장 중 거른 수 | – | 389 |
| Test 300장 | 284 | 280 |

## 후보 (지금 고정)

- **T1:** 채소 모델 점수만 4장 평균을 낸다. CLIP 분류기는 원본 한 장만 본다.
- **T2:** 채소 모델 점수와 CLIP 분류기 점수를 모두 4장 평균 낸다.
- **평균 뒤 다시 맞추는 값:** 지금과 같은 규칙으로 다시 맞춘다.
    - 채소 모델 온도: Valid
    - 채소 모델 거르기 기준: Valid + 실제 장면 채소 192장의 95%가 통과
    - CLIP 분류기 거르기 기준(T2만): Valid + 실제 장면 채소 192장의 95%가 통과
    - 합친 점수의 온도: Valid
- **둘 중 고르기:** Valid에서 합친 확률의 교차 엔트로피(NLL)가 더 낮은 쪽을 고른다.

## 판정 규칙

1. 채소 사진 네 묶음(Valid, 인터넷 채소, 160장 시험지, 아시아 오이, 모두 718장)의 맞게 남긴 수 합계가 **639장 이상**이어야 한다. 지금은 634장이므로 5장 넘게 좋아져야 한다.
2. 어느 묶음도 맞게 남긴 수가 지금보다 2장 넘게 줄면 안 된다. Valid 283, 인터넷 채소 171, 160장 시험지 143, 아시아 오이 29장 이상이어야 한다.
3. 거르기가 크게 나빠지면 안 된다. 인터넷 과일 234장 이상, 일상 사진 379장 이상을 걸러야 한다.
4. 1~3을 모두 넘으면 Test 300장을 한 번 채점한다. 정확도 284장 이상, 맞게 남긴 수 280장 이상이면 채택한다.

## 비용

- **T1:** 채소 모델을 4번 돌린다. 채소 모델은 가벼워서 사진 1장에 약 0.1초가 더 걸릴 것으로 본다.
- **T2:** CLIP도 4번 돌려서 사진 1장에 약 0.6초가 더 걸린다.
- 브라우저 데모에 넣으면 분석 시간이 4배가 된다.
