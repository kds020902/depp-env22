# CLIP 분류기에 "다섯 채소가 아님"을 직접 가르치기 (N3 채택)

CLIP 분류기에 11번째 클래스 "다섯 채소가 아님"(과일, 일상 사진, 다른 채소)을 더하고, 이 클래스일 가능성으로 사진을 거르게 했다.

> 2026.10.29: 이후 거르기 규칙을 CLIP 분류기 기준 하나로 바꿨다([clip_only_reject](../clip_only_reject/README.md)). 아래 숫자는 바꾸기 전(두 모델 중 하나라도 거르면 거름)의 것이다. 채소 쪽에는 약점 사진 등을 더했다. 채소 모델(EfficientNet-B0)은 바꾸지 않았다.

|---|---:|---:|
| **새 인터넷 시험지 241장** (봉인, 한 번 채점) | 191 (79.3%) | **203 (84.2%)** |
| 맞게 남긴 수 | 165 | **169** |
| **Test 300장** (한 번 채점) | 284 (94.7%) | **288 (96.0%)** |
| 맞게 남긴 수 | 280 | **282** |

| Valid 300장 | 288 (96.0%) | 291 (97.0%) |
| 160장 시험지 | 150 (93.8%) | 150 (93.8%) |

맞게 남긴 수: 정답이면서 "학습된 데이터가 아닙니다"로 거르지 않은 사진 수.

## 왜 했나

- [weak_spots](../weak_spots/README.md)와 [clip_head_more_data](../clip_head_more_data/README.md)에서, CLIP 분류기 학습 사진을 늘리면 채소는 더 맞혔지만 과일·일상 사진을 덜 걸렀다.
- 원인은 거르는 방식이었다. "얼마나 확신이 없는가"(energy)로 거르면, 다양한 사진으로 배울수록 기준이 느슨해진다.
- 그래서 "다섯 채소가 아님"을 직접 가르치고, 그 가능성으로 거르기로 했다.

## 바꾼 것 (`PREREG.md`)

- **CLIP 분류기:** 다항 로지스틱 회귀, C=10, 11클래스(채소 10 + 아님 1)
- **CLIP 쪽 거르기 점수:** "아님" 점수 − logsumexp(채소 10개 점수). 기준값은 이전과 같은 규칙이다(Valid + 실제 장면 채소 192장의 95%가 통과).
- **분류:** 채소 10개 점수만 쓴다. 채소 모델과 합치는 방식, 온도 맞추기(Valid)는 이전과 같다.
- **"아님" 사진 2,850장** (`added_photos.csv`의 not_five):
    - 과일 1,375장(kritikseth 11종, Fruits-262)
    - 일상 사진 1,106장(Caltech-101 606장, Places365 500장)
    - 다른 채소 374장(kritikseth 15종)
    - 고추·할라피뇨·고구마는 피망·감자와 닮아 뺐다.
    - 확인용 사진과 같은 사진 5장도 뺐다.
- **채소 쪽 추가 1,773장 (N3):**
    - 예전 검수 사진 1,168장
    - 약점 사진 434장([weak_spots](../weak_spots/README.md))
    - 사용자가 제안한 검색어("rotten/fresh asian 채소" 등 52개)로 찾은 사진 31장. 832장 중 눈으로 골랐다.
    - 동아시아 오이 140장([asian_cucumber](../asian_cucumber/README.md) J2의 Zenodo 사진)

## 진행 순서

1. **N1·N2 (`check_results.json`):** 개발용 확인에서 둘 다 탈락했다.
    - N1(Train + 아님): 인터넷 채소 190장으로 기준(190 초과) 미달, Valid 맞게 남긴 수 281, 아시아 오이 25
    - N2(N1 + 채소 사진 1,633장): 아시아 오이 맞게 남긴 수 28장으로 기준(29장)에 1장 모자랐다. 나머지는 모두 통과했다.
2. **원인:** 거른 아시아 오이 7장과 가장 비슷한 "아님" 사진은 수박·아보카도·완두·옥수수·바나나였다. 가늘고 돌기 있는 초록 오이가 채소 쪽 학습 사진에 거의 없어서다.
3. **N3 추가:** N2에 동아시아 오이 140장을 더했다. 이 후보는 N1·N2 결과를 본 뒤에 만들었고, `PREREG.md` 끝에 덧붙여 적었다.
4. **N3 개발용 확인:** 모두 통과했다. Valid 284, 160장 시험지 148, 아시아 오이 30, 과일 347, 일상 400, 인터넷 채소 199.
5. **마지막 채점 (`final_once.json`):** 새 시험지 241장과 Test 300장을 한 번씩 채점했다.
    - 채택 기준: 새 시험지 194장 이상, 맞게 남긴 수 165장 이상, Test 284장 이상, 맞게 남긴 수 280장 이상
    - 결과: 203 / 169 / 288 / 282로 모두 넘어 채택했다.

## 한계

- N3는 개발용 확인 결과를 보고 만든 후보다. 그래서 아시아 오이 37장 점수는 부풀었을 수 있다. 최종 판단은 아직 보지 않았던 새 시험지와 Test로 했다.
- Test는 채택 후보로 여섯 번째 채점이다.
- 새 시험지 기준 목표 92%(222장)에는 19장 모자란다.
    - 상한 토마토는 74장 중 55장, 상한 피망은 7장 중 2장을 맞힌다.
    - 진짜 채소 49장(20%)을 "학습된 데이터가 아닙니다"로 거른다.
- "아님" 사진에 과일이 있어, 확인용 인터넷 과일 거르기는 좋아지기 쉽다. 출처는 다르고 같은 사진은 뺐다.
- Valid에서 거르는 채소 사진이 3장에서 7장으로 늘었다.
- 사진을 돌리면 거르는 사진이 늘어난다([system_checks](../../results/10class/system_checks/README.md)).

## 다시 돌리기

`evaluate.py`와 `final.py`는 작업 폴더의 경로를 그대로 담고 있어서 기록용이다. 같은 분류기를 만드는 공식 방법은 다음과 같다.

```bash
# extra_train.csv: added_photos.csv의 사진을 내려받아 열을 path,class_name으로 만든 파일 (class_name: 10개 클래스 또는 not_five)
python src/train_clip_head.py --model model.pth --extra-photos lvis_vegetables --extra-train extra_train.csv
```

이 명령으로 다시 만든 분류기를 확인했다. Valid 291장, 거르기 기준 −0.6039(채택본 −0.6042), 온도 1.3667(채택본 1.3670)로 거의 같았다. 새 인터넷 시험지에서도 똑같이 203장을 맞히고 169장을 맞게 남겼다.

`PREREG.md`의 `../weak/PREREG.md`는 이 저장소의 [`../weak_spots/PREREG.md`](../weak_spots/PREREG.md)다. 사전등록 파일은 적은 그대로 두었다.
