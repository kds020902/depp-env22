# 아시아 오이로 학습하기 (1차·2차 모두 채택 안 함)

학습 데이터의 오이는 대부분 서양식(굵고 매끈한 진초록)이거나 방글라데시 시장 오이다. 한국·일본·중국 오이(가늘고 길며 가시·돌기가 있음)는 거의 없다. 그래서 두 가지를 확인했다.

- 현재 모델이 아시아 오이를 잘 맞히는가?
- 아시아 오이를 학습에 넣으면 나아지는가?

미리 정한 기준을 넘지 못해 `model.pth`는 그대로 두었다. Test는 채점하지 않았다.

## 확인용 사진: 아시아 오이 37장 (`asian_check.csv`)

- **출처:** 사람들이 Flickr와 Wikimedia Commons에 올린 한국·일본·중국 오이 사진이다. 미국·하와이에서 키운 아시아 품종 사진도 일부 있다.
- **검색:** 영어·한국어·일본어·중국어 검색어로 찾았다. 예: "korean cucumber", "오이", "きゅうり", "黄瓜".
- **고르는 기준:**
    - 받은 사진 약 1,300장을 한 장씩 보고, 아시아형 오이가 분명하고 통째로 보이는 정상 오이만 남겼다.
    - 요리, 밭에 달린 오이, 다른 채소와 섞인 사진, 늙어서 누렇게 된 오이는 뺐다.
- **중복 제외:** 3차 데이터, 인터넷 사진 221장, 160장 시험지와 같은 사진을 뺐다. 2장이 3차 데이터의 정상 오이와 같은 사진이라 빠졌다.
- **정답은 모델을 돌리기 전에 정했다.** 이 사진은 학습에 쓰지 않았다.
- **한계:**
    - 상한 아시아 오이는 공개 라이선스 사진을 찾지 못해 정상 사진만 있다.
    - 37장 중 5장은 같은 사람이 올린 사진이다.

| 모델 | 37장 중 맞힌 수 | 오이로는 맞힌 수 |
|---|---:|---:|
| B (현재 모델) | 30 (81%) | 34 |
| S7 (시드만 바꿈) | 32 | 35 |

비교하면 인터넷 사진 221장의 정상 오이(대부분 서양식)는 12장 모두 맞혔다.

B가 틀린 7장 중 4장은 가시·돌기가 많은 오이(한국 2장, 일본 1장, 중국 1장)를 "상한 오이"로 본 것이다. 돌기를 썩은 자국으로 읽은 것으로 보인다. 나머지 3장은 오이를 피망·당근·토마토로 봤다.

## 넣은 사진 (Train에만, 112장)

| 클래스 | 사진 | 출처 |
|---|---:|---|
| 정상 오이 | 60 | Zenodo "[Cucumber Dataset](https://zenodo.org/records/10081197)" (Jin Tao, CC BY 4.0) |
| 상한 오이 | 52 | Mendeley "[CUCUMBER](https://data.mendeley.com/datasets/zncrtr2yhn/1)" bad (CC BY 4.0) |

- **정상 오이 (Zenodo):** 오이 품종(유전자원) 수백 가지를 검은 천 위에 자·색상 카드와 함께 찍은 연구용 사진이다. 데이터 설명은 없지만, 길고 가시가 있는 동아시아형 품종이 많다.
    - 사진마다 오이 부분만 잘라냈다(`crop_zenodo.py`). 자와 색상 카드는 빠진다.
    - 품종마다 1장씩만 썼다.
    - 초록색 정상 오이 중 길고 가늘며 돌기가 있는 아시아형을 우선 골랐다. 씨를 받으려고 늙힌 노란색·흰색 오이는 뺐다.
- **상한 오이 (Mendeley):** 역시 검은 배경에서 찍은 사진이다. 넣은 이유는 "검은 배경 = 정상"을 배우지 않게 하려는 것이다.
    - [fix_carrot_cucumber](../fix_carrot_cucumber/README.md) 2차에서 검수를 통과한 76장 중 60장을 무작위로 골랐다.
    - 그중 서로 거의 같은 8장을 빼서 52장이 남았다.
- **중복 제외:** 기존 데이터·확인용 사진과 같은 사진은 없었다.
- **목록:** `added_photos.csv`에 있다. Zenodo 사진은 원본에서 자른 위치도 적었다.

## 미리 정한 규칙 (`PREREG.md`)

두 시드(J42, J7)의 합으로 판단한다. 대괄호는 B+S7의 값이다.

1. 아시아 오이 확인 사진 ≥ 68/74 [62]
2. Valid ≥ 549 [555], 인터넷 사진 221장 ≥ 329 [329], 160장 시험지 ≥ 294 [294]
3. 1·2를 넘으면 Valid가 높은 쪽으로 Test를 한 번 채점한다. 272장 이상일 때만 `model.pth`를 바꾼다.

## 무엇을 배웠나

- **아시아 오이에 약한 것은 사실이다.** 현재 모델은 서양식 정상 오이는 다 맞히지만, 아시아 오이는 81%만 맞힌다. 특히 가시·돌기가 많은 오이를 상했다고 본다.
- **연구용 사진으로는 고르게 고쳐지지 않았다.**
    - J42는 가시오이 오답 4장을 모두 고쳐 35장을 맞혔다.
    - 같은 사진으로 시드만 바꾼 J7은 B와 같은 30장이었고, 가시오이를 여전히 상했다고 봤다.
    - 검은 천 위 한 개씩 찍은 사진이 시장·부엌에서 찍은 사진으로 잘 옮겨 가지 않는 것으로 보인다.
- **160장 시험지에서 J42가 9장 떨어졌다.** 주로 오이가 아닌 상한 감자(11→7), 상한 당근(9→7), 정상 피망(18→16)에서 떨어졌다.
    - J7은 146장으로 S7과 같았다.
    - 학습 사진을 조금만 바꿔도 다른 채소 점수가 몇 장씩 흔들린다는 것을 다시 확인했다.
- **더 나아지려면 실제 환경에서 찍은 한국 오이 사진이 필요하다.**
    - 마트·부엌에서 찍은 정상 오이와 시간이 지나며 상해 가는 오이가 필요하다.
    - 공개 사진으로는 이번에 찾은 약 40장이 거의 전부였고, 모두 확인용으로 썼다.

## 2차 시도: 기존 오이와 동아시아 오이를 5:5로 (J2, 채택 안 함)

1차(J)에서는 동아시아 오이가 정상 오이 Train의 30%(60/200)였다. 이번에는 같은 수로 맞췄다. 기준은 학습 전에 `PREREG_J2.md`에 적었다(1차와 같은 기준).

**기존 정상 오이 140장의 종류** (눈으로 분류, `train_cucumber_types.csv`)

| 종류 | 장수 |
|---|---:|
| 서양식 (굵고 매끈한 진초록, 스톡·슬라이스 사진) | 72 |
| 남아시아 시장 오이 (방글라데시, 굵고 연두색) | 66 |
| 덩굴에 달림 / 판단 어려움 | 2 |
| 동아시아식 (가늘고 길며 가시가 있음) | 0 |

남아시아 시장 오이도 굵고 매끈해서 한국·일본·중국 오이보다 서양식에 가깝다. 그래서 **기존 140장 : 동아시아 140장**으로 맞췄다.

**바꾼 것 (Train에만)**

- **동아시아 정상 오이 140장:** 1차의 60장에 같은 Zenodo 사진에서 80장을 더했다(품종 40개, DSC 사진 22장, IMG 사진 18장).
    - 먼저 모양으로 추렸다. 길고(길이/폭 4 이상), 초록색이고, 허옇지 않은 오이다.
    - 그다음 눈으로 확인했다.
- **검은 배경 상한 오이 67장:** Mendeley 상한 오이 500장은 같은 오이를 여러 번 찍은 사진이라, 서로 다른 사진이 약 68장뿐이다. 그래서 정상 쪽(140장)만큼 늘리지 못하고 있는 만큼 넣었다.
- **결과:** 정상 오이 Train은 280장(5:5), 상한 오이는 207장이 됐다. 목록은 `added_photos_J2.csv`에 있다.

|---|---:|---:|---:|---:|---:|---:|
| B (현재 모델) | 281 | 167 | 148 | 30 | 23 | 2 |

**판정:** 채택하지 않았다. Test는 채점하지 않았다.

| 기준 | J2 결과 | 기준값 | 통과 |
|---|---:|---:|---|
| 아시아 오이 확인 사진 | 65 | 68 이상 | 미달 |
| Valid | 553 | 549 이상 | 통과 |
| 인터넷 사진 | 336 | 329 이상 | 통과 |
| 160장 시험지 | 283 | 294 이상 | 미달 |

**무엇을 배웠나**

- **5:5로 늘려도 1차와 같았다.** 아시아 오이 두 시드 합은 1차와 같은 65장이었다.
    - 한국 가시오이 1장(두 시드 모두), 화분에서 딴 중국 오이, 똬리처럼 말린 오이, 일본 마트 진열 사진은 계속 틀렸다.
    - 같은 연구용 사진을 더 넣는 것으로는 실제 사진의 아시아 오이가 더 나아지지 않았다.
- **160장 시험지는 오이를 더할 때마다 떨어졌다.** 두 시드 합이 1차 285장, 2차 283장이었다(B+S7 294장).
    - 가장 크게 떨어진 것은 상한 감자다. 12장 중 B는 11장을 맞혔고, J·J2 네 모델은 6~9장을 맞혔다.
    - 오이 사진만 바꿨는데 감자가 흔들렸다.
- **"검은 배경 = 정상" 쏠림은 작았다.** Valid 상한 오이 30장 중 정상으로 본 것은 B 1장, J2_42 2장, J2_7 1장이었다.
- **결론:** 공개된 연구용 사진으로는 이 이상 나아지기 어렵다. 실제로 찍은 한국 오이 사진이 필요하다.

## 다시 돌리기

```bash
# 확인용 사진 받기·채점
python results/10class/outside_test/evaluate.py fetch --csv experiments/asian_cucumber/asian_check.csv --photos asian_photos
python results/10class/outside_test/evaluate.py run --csv experiments/asian_cucumber/asian_check.csv --photos asian_photos --model model.pth

# 학습 사진: Zenodo zip(2.3GB)에서 잘라내기 (1차 60장 / 2차 140장)
python experiments/asian_cucumber/crop_zenodo.py "Cucumber Dataset.zip" zenodo_crops
python experiments/asian_cucumber/crop_zenodo.py "Cucumber Dataset.zip" zenodo_crops_J2 added_photos_J2.csv
```

상한 오이는 Mendeley CUCUMBER에서 `added_photos.csv`(2차는 `added_photos_J2.csv`)의 파일을 받아 긴 변 640픽셀로 줄인다. 두 묶음을 3차 데이터의 Train 폴더에 더하고, Test 행을 뺀 manifest로 학습한다. 학습 설정은 `model.pth`와 같다(`--epochs 30 --patience 8`, 시드 42·7).
