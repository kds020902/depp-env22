# 과일을 "기타" 클래스로 학습해 거르기 (채택 안 함)

지금 모델은 과일 사진을 "학습된 데이터가 아닙니다"로 거를 때 출력 점수(energy)만 본다. 그래서 채소와 닮은 과일은 그대로 통과한다. 데모의 오렌지는 정상 토마토로, 썩은 사과는 상한 토마토로 판정된다.

과일 사진을 직접 보여 주며 11번째 클래스 "기타(other)"로 학습시켜 봤다.
- **과일 거르기:** 크게 좋아졌다.
- **채소:** 둥글고 매끈한 채소를 과일로 보는 실수가 생겨 채소 점수가 떨어졌다.

미리 정한 기준을 넘지 못해 `model.pth`는 그대로 두었고, Test는 채점하지 않았다.

## 바꾼 것

- **11번째 클래스 "other":** 판정 규칙은 다음과 같다.
    - 가장 높은 클래스가 other이면 "학습된 데이터가 아닙니다"로 답한다.
    - other가 아니어도 energy 점수가 기준보다 높으면 같은 답을 한다.
    - energy 기준은 Valid의 채소 사진 300장 중 95%가 통과하는 값으로 정했다. 과일 사진은 기준을 정할 때 넣지 않았다.
- **과일 사진:** Train 287장, Valid 30장이다. 모두 CC0이고, 눈으로 확인했다. 목록은 `added_photos.csv`에 있다.

| 출처 | Train | Valid | 과일 |
|---|---:|---:|---|
| [Fruits and Vegetables Dataset](https://www.kaggle.com/datasets/muhriddinmuxiddinov/fruits-and-vegetables-dataset) `Fruits` 폴더 (채소와 같은 데이터) | 100 | 10 | 사과·바나나·망고·오렌지·딸기 × 정상·상함 |
| [kritikseth fruit-and-vegetable-image-recognition](https://www.kaggle.com/datasets/kritikseth/fruit-and-vegetable-image-recognition) | 88 | 11 | 과일 11종 (포도·배·파인애플·석류·수박 등) |
| [Fruits-262](https://www.kaggle.com/datasets/aelchimminut/fruits262) | 99 | 9 | 과일 33종 (감·귤·대추·유자·배·참외와 비슷한 멜론 등) |

- **복사본 제외:** 아래 확인용 사진과 같은 사진, 기존 채소 사진과 같은 사진은 모두 뺐다.
- **일부러 학습에서 뺀 과일:** 살구·체리·천도복숭아 등 5종이다. 처음 보는 과일도 걸러지는지 보려는 것이다.
- **바꾸지 않은 것:** 채소 사진, 모델(EfficientNet-B0), 학습 설정은 그대로다. 코드 변경은 `other_class.patch`에 있다.

## 무엇을 배웠나

- **과일을 직접 학습시키면 과일은 잘 걸러진다.**
    - 인터넷 과일은 61%에서 88%로 올랐다.
    - 학습에 없는 과일(살구·체리·복숭아·자두·참외)도 51%에서 90%로 올랐다.
    - 데모의 오렌지·썩은 사과도 걸렀다.
- **감은 여전히 절반 이상 통과한다.** 23장 중 9~11장만 걸렀다. 주황색으로 둥글고 매끈해서 토마토와 아주 닮았다.
- **대신 둥글고 매끈한 채소를 과일로 본다.**
    - 인터넷 채소 221장 중 22~32장을 과일로 봤다. 대부분 토마토·감자다.
    - 160장 시험지에서는 정상 감자 20장 중 3~5장을 과일로 봤다.
    - 과일로 보지 않은 사진도 흔들렸다. 정상 피망(18 → 10·15장)과 상한 감자(11 → 7장)가 떨어졌다.
- **과일과 채소의 경계에 있는 사진이 양쪽 모두 부족하다.**
    - 사진 한 장으로는 토마토와 감, 감자와 배의 차이가 작다.
    - 과일 쪽에 사진을 더 넣을수록 비슷한 채소가 과일 쪽으로 끌려간다.

## 다시 돌리기

```bash
git apply experiments/fruit_other/other_class.patch   # --num-classes 11 과 other 클래스
python src/train.py --manifest <채소 + other manifest_notest.csv> --out runs/O42 --arch efficientnet_b0 --mode finetune --epochs 30 --patience 8 --seed 42 --num-classes 11
python results/10class/outside_test/evaluate.py fetch --csv experiments/fruit_other/fruit_check.csv --photos fruit_photos
```

과일 사진은 `added_photos.csv`의 파일을 세 Kaggle 데이터에서 받아 긴 변 640픽셀로 줄인다. manifest에는 `class_name=other`, `class_id=10`으로 넣는다.
