# CLIP 문지기: "다섯 채소인가?"만 묻기 (규칙상 채택 안 함, 1장 차이)

지금 채소 모델(B) 앞에 CLIP을 두고 "오이·감자·토마토·피망·당근 중 하나인가?"만 물었다. 과일 이름을 맞히려는 것이 아니라 "이 다섯 채소가 아닙니다"라고 답하기 위해서다.

- **좋아진 것:** 과일과 일상 사진 거르기가 크게 좋아졌다. 인터넷 과일은 27%에서 94%, 일상 사진은 78%에서 98%를 거른다.
- **나빠진 것:** 채소는 조금 놓쳤다. 대부분 상한 토마토를 감·대추·복숭아로 본 경우다.
- **판정:** 미리 정한 기준 중 160장 시험지가 141장으로 기준(142장)에 1장 모자라 채택하지 않았다. Test는 채점하지 않았다.

## 방법 (`PREREG.md`)

- CLIP은 인터넷 사진 수억 장으로 학습한 공개 모델이다(Radford et al. 2021). 과일과 채소의 차이를 이미 안다.
- 판정 순서는 다음과 같다.
    1. 문지기가 "다섯 채소가 아니다"라고 보면 거른다.
    2. 통과한 사진은 지금과 똑같이 B가 답한다(energy 기준 −1.962 포함). B는 바꾸지 않았다.
- **후보 4개:** CLIP 2종(OpenAI ViT-B/16, DataComp-XL ViT-B/16) × 방법 2종으로 정했다.
    - **글자로 묻기:** 사진을 단어 90개와 비교해 다섯 채소일 확률을 낸다. 단어는 다섯 채소, 과일 40, 다른 채소 26, 그 밖 19개이고 학습은 없다.
    - **사진으로 가르치기:** 과일 문지기 2차 학습 사진(채소 3,147장, 과일 2,667장)으로 선형 분류기를 학습했다.
- **기준값:** Valid 채소 300장과 실제 장면 채소 192장 중 99%가 통과하는 값으로 정했다.
- **후보 고르기:** 개발용 사진(LVIS 실제 장면 과일 192장)만 보고 하나를 골랐다. 확인용 사진은 고른 뒤 한 번만 채점했다.

## 문지기가 잘못 거른 채소

확인용 채소 사진 중 15장을 걸렀다(Valid 2, 인터넷 채소 8, 160장 시험지 5). 괄호 안은 CLIP이 가장 가깝다고 본 것이다.

- **토마토 10장 (상한 9, 정상 1):**
    - 대부분 아랫부분이 검게 썩거나 쭈글쭈글한 토마토다. 정상 1장은 노랗게 덜 익은 토마토다.
    - CLIP은 감·대추·복숭아·대추야자로 봤다.
    - 160장 시험지에서 거른 5장(정상 1, 상한 4)이 모두 이 경우다.
- **싹 난 감자 2장:** 무화과, 순무로 봤다.
- **마른 당근 1장:** 고추로 봤다.
- **Valid의 줄무늬 작은 오이 1장과 상한 피망 1장:** 참외, 파파야로 봤다.
- **데모 11번(일부만 상한 토마토):** 감으로 봐서 걸렀다.

CLIP은 "상한 토마토"가 어떻게 생겼는지 잘 모른다. 주황색으로 둥글고 쭈글쭈글하면 감·대추와 구별하지 못한다.

## 무엇을 배웠나

- **처음으로 양쪽을 함께 좋게 만든 방법이다.**
    - 예전 기준(Valid만)과 비교하면 채소 맞게 남긴 수(138 → 155)와 과일 거른 수(233 → 353)가 모두 더 좋다.
    - 지금 기준과 비교하면 채소 3~5장을 내주고 과일 252장을 더 거른다.
- **남은 약점은 상한 토마토 하나다.**
    - 고치려면 상한 토마토 단어를 더 넣거나 사진으로 가르치는 방법을 섞을 수 있다.
    - 하지만 약점을 확인용 사진에서 찾았으므로, 고친 뒤에는 새 확인용 사진으로 다시 확인해야 한다.
- **쓰려면 비용이 있다.**
    - CLIP 모델은 약 600MB이고 처음 쓸 때 내려받는다.
    - 사진 1장에 CPU로 약 0.2초가 더 걸린다.
    - 지금 데모 페이지(브라우저에서 실행)에 넣기는 어렵다.
