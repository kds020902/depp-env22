# CLIP 특징 분류기를 채소 모델과 함께 쓰기 (채택)

지금 채소 모델(B, EfficientNet-B0)에 CLIP으로 만든 두 번째 분류기를 더했다. 두 모델의 판단을 합쳐 답한다. 둘 중 하나라도 "학습한 채소가 아니다"라고 하면 거른다.

- Test 정확도: 91.7% → **94.7%** (275 → 284장)
- 인터넷 채소 사진 221장 정확도: 75.6% → **86.0%** (167 → 190장)
- 과일·일상 사진 거르기: 과일 27% → 65%, 일상 사진 78% → 97%

교수님이 "외부 모델이든 무엇이든 개선만 되면 된다"고 하셔서 진행했다.

## 방법 (`PREREG.md`)

- **CLIP 특징:** CLIP(DataComp-XL ViT-B/16)은 인터넷 사진 수억 장으로 학습한 공개 모델이다. 사진 한 장을 숫자 512개(특징)로 바꿔 준다.
- **CLIP 분류기:** 그 특징 위에 우리 10개 클래스 분류기(다항 로지스틱 회귀, C=10)를 Train 1,260장으로만 학습했다. CLIP 자체는 다시 학습하지 않는다.
- **합치기:** 두 모델의 로그 확률을 더해 답을 정하고, 합친 점수의 온도를 Valid로 맞췄다.
- **거르기:** 두 모델이 각자 "학습된 데이터가 아닙니다" 기준을 가진다. 둘 다 Valid와 실제 장면 채소 192장의 95%가 통과하는 값이다. 둘 중 하나라도 걸리면 거른다.

## 진행 순서와 결과

**1. Valid로만 미리 보기 (확인용 사진을 보기 전)**

| | Valid 정답 |
|---|---:|
| B (지금) | 281 |
| OpenAI CLIP 분류기 (C=10) | 281 |
| DataComp CLIP 분류기 (C=10) | **288** |

**2. 미리 정한 규칙으로 고른 후보: CLIP 분류기만 (P, 채택 안 함)**

- Valid 교차 엔트로피로 P(분류기만)와 BP(B와 합치기) 중 P가 골라졌다.
- 인터넷 사진에서는 크게 좋아졌다. 정확도 203/221, 맞게 남긴 수 158 → 194였다.
- 하지만 160장 시험지에서 128장으로 기준(142)에 크게 못 미쳤다.
    - 정상 토마토 20장 중 10장, 정상 피망 18장 중 7장을 비정상으로 봤다.
    - CLIP 분류기는 채소 종류는 잘 알아보지만, 정상·상함 구분은 B보다 약했다.

**3. 결과를 본 뒤 만든 후보: B와 합치기 + 둘 중 하나라도 거르면 거름 (채택)**

- B는 정상·상함 구분에 강하고, CLIP 분류기는 실제 사진에 강하다. 그래서 둘을 합쳤다.
- B와 합치기만 하고 합친 점수로 거르면, 일상 사진을 245장만 걸렀다. 그래서 두 모델의 거르기 기준을 각각 쓰고, 하나라도 걸리면 거르게 했다.
- 이 후보는 확인용 사진을 본 뒤 만든 것이라, Test로 마지막 확인을 하기 전에 그 사실을 `PREREG.md`에 적었다.

| | B (지금) | 합친 모델 | 기준 | 통과 |
|---|---:|---:|---:|---|
| 인터넷 채소 221장 정확도 | 167 | **190** | – | – |
| 인터넷 채소 221장 맞게 남긴 수 | 158 | **173** | 163 이상 | 통과 |
| 160장 시험지 정확도 | 148 | 150 | – | – |
| 160장 시험지 맞게 남긴 수 | 146 | 145 | 142 이상 | 통과 |
| 아시아 오이 37장 맞게 남긴 수 | 29 | 31 | 27 이상 | 통과 |
| Valid 300장 맞게 남긴 수 | 278 | 285 | 278 이상 | 통과 |
| 인터넷 과일 374장 중 거른 수 | 101 | **244** | 91 이상 | 통과 |
| 일상 사진 400장 중 거른 수 | 311 | **389** | 301 이상 | 통과 |

**4. Test 300장 한 번 채점 (`test_once.json`)**

| Test 300장 | B (지금) | 합친 모델 |
|---|---:|---:|
| 정확도 (10개 클래스) | 275 (91.7%) | **284 (94.7%)** |
| 채소 종류만 | 288 | 291 |
| 정상·상함만 | 286 | 291 |
| 비정상 150장 중 비정상으로 맞힌 수 | 143 | 144 |
| 정상 150장 중 정상으로 맞힌 수 | 143 | 147 |
| 맞게 남긴 수 | 272 | **280** (기준 272 이상, 통과) |
| 거른 수 | 5 | 7 |

- 합친 모델이 새로 맞힌 사진은 10장이다. 정상 피망 3장, 그리고 오이·감자·토마토·당근이 한두 장씩이다.
- 새로 틀린 사진은 1장이다. 상한 피망을 상한 토마토로 봤다.

## 해석

- **실제 사진에 강해졌다.** 인터넷 채소 정답이 23장 늘었고(+10%p), Test도 9장 늘었다. CLIP이 다양한 사진을 보고 배운 특징이 우리 학습 사진의 좁은 분위기를 보완했다.
- **과일과 일상 사진도 더 잘 거른다.** 과일은 101장에서 244장, 일상 사진은 311장에서 389장을 거른다. 두 모델이 서로 다른 이유로 낯선 사진을 알아보기 때문이다.
- **정상·상함 구분은 여전히 B가 맡는다.** CLIP 분류기만 쓰면 멀쩡한 토마토·피망을 상했다고 보는 경우가 많았다.
- **이전 CLIP 문지기와 다른 점:** 문지기는 "다섯 채소인가?"를 글자로만 물어서, 많이 상한 채소를 과일로 보고 걸렀다. 이번 분류기는 우리 Train 사진(상한 채소 포함)으로 배웠기 때문에 상한 채소를 채소로 알아본다.

## 비용과 한계

- 사진 1장에 CPU로 약 0.3초 걸린다(B만 쓰면 더 빠르다). CLIP(약 600MB)은 처음 쓸 때 내려받는다.
- `pip install open_clip_torch`가 필요하다. `predict.py --no-clip`으로 B만 쓸 수 있다.
- 브라우저 데모는 CLIP이 너무 커서 여전히 B만 쓴다.
- 최종 후보는 확인용 사진 결과를 본 뒤 만들었다. Test는 이 계열에서 처음 본 것이지만, 이 프로젝트에서 채택 후보마다 한 번씩, 다섯 번째로 채점한 것이다.

## 다시 만들기

```bash
pip install open_clip_torch scikit-learn
python experiments/real_scene_threshold/crop_lvis.py lvis-fruits-and-vegetables-dataset.zip lvis_vegetables
python src/train_clip_head.py --model model.pth --extra-photos lvis_vegetables
```

`train_clip_head.py`는 CLIP 분류기, 합친 온도(1.356), CLIP 쪽 거르기 기준(−3.437)을 `model.pth`의 `clip_head`에 넣는다. 이렇게 만든 `model.pth`로 Test를 다시 돌리면 맞게 남긴 수가 같은 280장이 나온다.
