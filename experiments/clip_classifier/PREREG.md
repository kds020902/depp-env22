# CLIP 특징으로 10개 클래스 분류하기, 확인용 사진을 보기 전에 적음 (2026-10-24)

## 왜 하나

- 교수님이 "외부 모델이든 무엇이든 개선만 되면 된다"고 하셨다.
- 지금 모델(B)의 가장 큰 약점은 실제로 찍은 사진이다. Test는 91.7%인데, 인터넷 채소 사진 221장에서는 75.6%다.
- CLIP은 인터넷 사진 수억 장으로 학습해서, 사진 분위기가 달라져도 잘 버틴다고 알려져 있다(Radford et al. 2021).
- 그래서 CLIP 이미지 특징 위에 우리 10개 클래스 분류기를 학습시킨다.

## 이미 본 것 (Valid만)

이 문서를 쓰기 전에 Valid 300장으로만 다음을 봤다. 확인용 사진(인터넷 채소, 160장 시험지, 아시아 오이, 과일, 일상 사진)과 Test는 보지 않았다.

| | Valid 정답 |
|---|---:|
| B (지금) | 281 |
| OpenAI CLIP + 분류기 (C=0.3, 1, 3, 10) | 273, 276, 280, 281 |
| DataComp CLIP + 분류기 (C=0.3, 1, 3, 10) | 284, 284, 286, **288** |
| B + DataComp 분류기 (C=10) | 288 |

## 후보 (지금 고정)

- **특징:** open_clip ViT-B-16 `datacomp_xl_s13b_b90k`의 이미지 특징이다. L2 정규화하고, 전처리는 open_clip 기본값을 쓴다.
- **분류기:** 다항 로지스틱 회귀, C=10이다. Train 1,260장으로만 학습한다.
- **두 가지 중 하나를 Valid로 고른다.**
    - P: 분류기만 쓴다.
    - BP: B와 분류기를 합친다. 각각의 로그 확률을 더하고, B는 지금 온도 0.528을 쓴다.
    - 각자 Valid로 온도를 다시 맞춘 뒤, Valid 교차 엔트로피(NLL)가 더 낮은 쪽을 고른다.
- **"학습된 데이터가 아닙니다" 기준:** 지금과 같은 규칙으로 다시 정한다. 고른 후보의 점수에서 −logsumexp를 구하고, Valid 300장과 LVIS 실제 장면 채소 192장의 95%가 통과하는 값으로 한다.

## 판정 규칙 (지금 방식과 비교)

지금 방식은 B와 기준 −1.962의 조합이다. "맞게 남긴 수"는 거르지 않고 종류·상태까지 맞힌 수다.

| | 지금 | 통과 기준 |
|---|---:|---:|
| 인터넷 채소 221장 맞게 남긴 수 | 158 | **163 이상** (5장 넘게 좋아질 것) |
| 160장 시험지 맞게 남긴 수 | 146 | 142 이상 |
| 아시아 오이 37장 맞게 남긴 수 | 29 | 27 이상 |
| Valid 300장 맞게 남긴 수 | 278 | 278 이상 |
| 인터넷 과일 374장 중 거른 수 | 101 | 91 이상 |
| 일상 사진 400장 중 거른 수 | 311 | 301 이상 |

- 모두 넘으면 Test 300장을 한 번 채점하고, Test 맞게 남긴 수가 272장 이상(지금 272장)이면 채택한다.
- 함께 적을 숫자: 거르지 않고 본 정확도(인터넷 채소, 160장 시험지, Test).

## 미리 밝혀 둘 점

- 확인용 사진은 이전 실험에서 여러 번 봤다. 이번 후보는 Valid만 보고 정했지만, 완전히 새 시험지는 아니다.
- Test도 이전에 채택 후보마다 한 번씩 채점했다(학습 데이터 늘리기, 과일 문지기, 채소 놓치지 않기, CLIP 문지기). 이번이 다섯 번째다.
- 채택하면 사진마다 CLIP(약 600MB)을 돌려야 한다. 브라우저 데모에는 바로 넣기 어렵다.
