# 새 사진 없이 판정 개선하기: 계획 (결과를 보기 전에 적음, 2026-11-02)

## 배경
- 웹 사진을 더 넣는 방식(K1~K4, L1·L2, B1)은 세 번 연속 효과가 거의 없었다.
- 직접 찍은 사진은 지금 모을 수 없다(사용자).
- 그래서 같은 사진에서 더 많은 것을 뽑는 세 가지를 순서대로 해 본다(사용자 결정: 2 → 3 → 4, 새 블라인드 테스트셋 T5는 나중에).

**공통 규칙**
- 기준 모델은 TV-12다. 채소 모델(EfficientNet-B0)은 바꾸지 않는다.
- 개발용 확인은 experiments/t3_weak_spots와 같은 사진·같은 8가지 조건으로 한다(Valid, 첫 인터넷 221, 160장, 아시아 오이 37, 일상 400, 새 채소 Valid, 약점 개발용 2회차, 옛 개발용 → 새 채소).
- **"개선"의 뜻:** 다섯 채소 개발용 전체(Valid + 221 + 160 + 아시아 37 = 718장)에서 맞게 남긴 수가 **+5장 이상**이다(약 0.7%p). 그보다 작으면 "효과 미미"로 적는다.
- 개발용 조건을 모두 지키고 개선이어도 바로 채택하지 않는다. 블라인드 테스트셋(T3·T4)은 이미 한 번씩 썼으므로, 채택은 T5로 정한다(나중에).
- 2의 결과가 개선이면 3과 4는 2의 후보 위에서 한다. 아니면 TV-12 위에서 한다.

## 2. CLIP 분류기에 글 설명 점수 섞기 (후보 Z)
- **방법:** CLIP 분류기의 10개 클래스 점수에 α × (CLIP 글 설명 점수)를 더한다.
    - 글 설명 점수 = 100 × cos(사진, 클래스 글 설명). 사진마다 10개 클래스 평균을 빼서 가운데를 맞춘다.
    - 새 채소 분류기(V7, TV-10)가 이미 쓰는 방법과 같다.
    - 글 설명은 V7이 쓰는 10개 클래스 문장을 그대로 쓴다("a photo of a rotten tomato.", "a photo of a moldy tomato." 등). 개발용 사진을 보고 문장을 고치지 않는다.
    - "다섯 채소 아님" 점수 칸은 그대로 둔다.
- **다시 맞추는 것 (TV-12와 같은 규칙):**
    - 두 모델을 합치는 온도: Valid로 맞춘다.
    - 거르기 기준: Valid + LVIS 192장의 95%가 통과하도록 맞춘다(글 설명 거르기 α 0.25 포함).
    - 새 채소 분류기와 τ 0.8은 그대로다.
- **후보:** α = 0.1, 0.25, 0.5, 1.0 (Z010, Z025, Z050, Z100).
- **고르는 규칙:**
    1. 8가지 조건을 모두 지킨 후보 중에서 고른다.
    2. 다섯 채소 개발용 전체 점수가 가장 높은 것을 고른다.
    3. 같으면 약점 개발용 점수, 그래도 같으면 작은 α를 고른다.
- 참고로 글 설명만 쓴 경우(α → ∞, 분류기 없이)의 개발용 정답률도 적는다. 고르는 데는 쓰지 않는다.

## 3. 사진을 조각내서 보기 (후보 C)
- **방법:**
    - 사진마다 조각 5개를 만든다: 네 모서리와 가운데에서 가로·세로 2/3 크기로 자른다.
    - 조각마다 CLIP 특징을 뽑는다.
    - 시스템이 전체 사진으로 "정상 X"라고 답했을 때만, 조각들의 CLIP 분류기 점수에서 "상한 X / (정상 X + 상한 X)"의 최댓값을 본다. 이 값이 t 이상이면 답을 "상한 X"로 바꾼다.
- **바꾸지 않는 것:**
    - 상함 → 정상으로는 바꾸지 않는다(상함을 놓치는 오류가 더 위험하므로).
    - 채소 종류와 거르기도 바꾸지 않는다.
- **후보:** t = 0.6, 0.7, 0.8, 0.9.
- **고르는 규칙:** 2와 같다(8가지 조건 → 다섯 채소 전체 → 약점 개발용 → 큰 t).
- **함께 적는 것:** 개발용에서 상함을 새로 찾은 수와, 정상을 상함으로 잘못 바꾼 수.

## 4. 모르면 모른다고 하기 (판단 보류)
- **지금:** 확률이 90% 미만이면 답과 함께 "다시 찍어 보세요"를 붙인다. 답은 그대로 보여 준다.
- **바꾸는 것:** 확률이 q 미만이면 답 대신 "판단 보류: 가장 가까운 답은 X (확신 낮음)"라고 답한다.
    - 그 불확실함이 같은 채소의 정상/상함 사이이면 "상했을 수 있으니 직접 확인하세요"를 붙인다.
- **곡선:** 개발용 사진마다 q = 0.5, 0.6, 0.7, 0.8, 0.9에서 다음을 적는다.
    - 답한 비율
    - 답한 사진의 정답률
    - 보류한 사진 중 실제로 틀렸을 사진의 비율
- **q를 고르는 규칙:**
    - 바깥 개발용 사진(첫 인터넷 221 + 160장 + 아시아 오이 37)에서, 답한 사진의 정답률이 95% 이상이 되는 가장 작은 q를 고른다.
    - 그런 q가 없으면 지금 기준 0.9를 그대로 쓴다.
- 4는 점수(맞힌 수)를 바꾸지 않는다. 바뀌는 것은 "자신 있게 틀린 답"의 수다. 그래서 위의 "+5장" 기준은 4에 쓰지 않는다.
