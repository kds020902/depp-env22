## 바꾸는 것: 후보 V4

1. **채소 모델(EfficientNet-B0):** 지금과 같은 설정(전체 미세조정, 증강, 라벨 스무딩 0.1, 30 epoch, Valid 손실로 epoch 선택)으로 16칸을 학습한다.
    - Test가 열리지 않게 Test 행을 뺀 manifest로 학습한다.
    - 시드 42와 7 두 번 학습하고, Valid(335장) 정확도가 높은 쪽을 쓴다. 같으면 Valid 손실이 낮은 쪽이다.
    - 확률 보정과 채소 모델 거르기 기준은 지금과 같은 규칙(Valid + 실제 장면 채소 192장의 95%)이다.
2. **CLIP 분류기:** N3와 같은 사진에 새 채소 Train 사진을 더한다.
    - "다섯 채소가 아님" 쪽에 있던 kritikseth 양파·고구마 사진 50장은 뺀다. 이제 학습할 채소이기 때문이다.
    - 설정은 그대로다(다항 로지스틱 회귀, C=10). 출력은 16칸 + "아님"이다.
3. **합치기·거르기:** 지금과 같다. 두 모델을 1:1로 합치고 온도는 Valid로 맞춘다. 거르기는 R1(CLIP "아님" 로그 오즈)이고, 기준은 Valid + 실제 장면 채소 192장의 95%다.
4. **대파:** 답이 "대파 정상"이면 "대파 (상태 판정 안 함)"으로 보여 준다.
