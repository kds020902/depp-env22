# 대파·상한 고구마·상한 양파 보강 (v6), 결과를 보기 전에 적음 (2026-10-31)

V5-H의 약점은 두 가지였다.
- 대파: 새 채소 시험지 1에서 10/20장을 맞혔다.
- 상한 고구마: 두 시험지를 합쳐 3/11장을 맞혔다.

사용자 요청은 "이거 더 개선하고 이미지 개수를 평균에 맞추보자"이다. 그래서 세 클래스의 사진을 더 모았다. 모자란 클래스는 증강으로 평균까지 채운 것도 함께 확인한다.

## 데이터 (`pool.json`)

- v4·v5 사진의 나누기는 그대로 둔다.
- 이번에 105장을 더 눈으로 검수했다.
    - iNaturalist 87장
    - 위키미디어 공용 9장
    - LVIS 잘라낸 사진 8장
    - Openverse 1장
- 예전 사진(봉인 시험지 포함)과 CLIP 코사인 0.95 이상인 사진은 없었다.
- 나누기 규칙은 v4·v5와 같다.
    - 올린 사람 단위로 나눈다.
    - 이미 있던 사람은 같은 쪽에 둔다.
    - 봉인 시험지에 사진을 올린 사람은 시험지 쪽에 둔다.
    - 새로 시험지로 가는 사진은 클래스마다 1/3까지다.
- 이번에 시험지 쪽으로 간 21장은 **새 채소 시험지 3**으로 봉인한다.
- 공개 사진을 끝까지 찾았지만 상한 고구마는 더 구하지 못했다.
    - Openverse는 결과 대부분이 이미 본 사진이었다.
    - 위키미디어는 요청 제한이 걸렸다.
    - 찾은 공개 데이터셋 AgriFreshNET에는 고구마·양파가 없었다.

## 후보

판정 방식은 V5-H와 같다.
1. 지금 시스템이 먼저 답한다.
2. 지금 시스템이 거른 사진은 새 CLIP 분류기가 다시 본다.
3. 지금 시스템이 답한 사진은, 새 채소 확률이 τ 이상일 때만 새 분류기의 답으로 바꾼다.

τ도 V5-H와 같은 규칙으로 정했다. 0.5 / 0.7 / 0.8 / 0.9 / 0.95 중, 기존 채소 개발용 사진 910장에서 3번 규칙으로 새 채소로 바뀌는 사진이 1장 이하인 가장 낮은 값이다.

- **V6-H (채택 대상):**
    - 새 CLIP 분류기를 v6 사진(Train 348장)으로 다시 학습한다. 다른 설정은 V5-H와 같다.
    - τ = 0.7, "아님" 기준은 −1.094다.
- **V6-A (기록용, 채택하지 않음):**
    - V6-H에 증강을 더했다. 평균(70장)보다 적은 클래스의 Train 사진을 무작위로 자르고(60~100%), 뒤집고, 색을 조금 바꿔 평균까지 채웠다(seed 0).
    - 채운 수는 상한 양파 10장, 상한 고구마 38장이다.
    - 같은 규칙에 따라 τ = 0.8이 됐다. 증강을 넣으면 0.7에서 기존 채소 2장이 새 채소로 바뀌었기 때문이다.
- **V6-H를 고른 이유 (개발용 새 채소 Valid 73장):**
    - 종류를 맞히고 거르지 않은 수는 V5-H 53, V6-H 60, V6-A 58이다.
    - 증강은 개발용 사진에서 나아지지 않았다.
    - 사용자가 요청한 방법이라 V6-A도 같은 때에 한 번 채점해 기록한다.

## 미리 밝혀 둘 점

- 새 인터넷 시험지와 Test는 여러 번 쓴 시험지다. 기존 채소 실력은 새 봉인 시험지로 다시 재는 것이 좋다.
- 상한 고구마 실제 사진은 32장으로 평균(70장)에 못 미친다. 증강(V6-A)은 개발용 사진에서 도움이 되지 않았다.
- 대파 사진에는 리크(서양 대파)도 들어 있다. v4·v5와 같은 기준이다.
