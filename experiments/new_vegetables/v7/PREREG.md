# 상한 고구마·대파 개선 (v7), 결과를 보기 전에 적음 (2026-11-01)

사용자 요청: "상한 고구마랑 대파 더 개선해보자"

V6-H의 약점은 새 채소 시험지 1·2·3 기준으로 두 가지다.
- 상한 고구마: 종류를 맞힌 사진이 16장 중 7장
- 대파: 33장 중 22장

## 1. 무엇이 문제인지 (개발용 사진만 씀)

v6 사진으로 Train을 올린 사람 단위 5묶음 교차검증(CV)을 했다.
- **상한 고구마:** V6-H는 32장 중 10장만 맞혔다. 가장 흔한 실패는 다섯 채소 시스템이 "감자 비정상"으로 답하는 경우다. 새 분류기도 고구마로 보지만 새 채소 확률이 기준(τ)에 못 미쳐 답을 바꾸지 못한다.
- **대파:** CV에서 79장 중 69장을 맞혔다. 실패는 양파로 보거나, "아님"으로 거르거나, 다섯 채소 시스템이 오이·당근으로 답한 경우다.
- **시험해 본 방법 (v6 사진, `explore_v6.json`):**
    - **CLIP 글 설명 섞기:** "a photo of a sprouting sweet potato" 같은 클래스별 글 설명과 사진의 유사도(CLIP zero-shot)를 비율 α만큼 새 분류기 점수에 더했다. CV는 280 → 287(α 0.1) → 293(0.25) → 294(0.5)로 늘었다. 기존 채소 개발용 사진에서 새 채소로 잘못 보낸 수도 줄었다.
    - **클래스 균형 가중치:** 오히려 나빠졌다(CV 266).

## 2. 데이터 (`pool.json`)

- v4~v6 사진의 나누기는 그대로 둔다.

## 3. 후보 고르는 규칙 (v7 사진의 개발용 결과를 보기 전에 정함)

- **후보 네 개:**
    - base: V6-H 방법 그대로 v7 사진으로 다시 학습
    - zs0.1 / zs0.25 / zs0.5: base에 CLIP 글 설명을 α만큼 섞음
- **공통 설정:** "아님" 기준은 95% 규칙으로, τ는 V5/V6과 같은 규칙으로 정한다.
- **고르는 방법:** 기존 채소 개발용 확인을 통과한 후보 중 v7 CV의 "종류 맞고 안 거름" 수가 가장 큰 것을 고른다.
    - 개발용 확인 기준: Valid 288/284, 인터넷 221 195/186, 160장 147, 아시아 31, 과일 거름 320, 일상 거름 395
    - 단, 새 채소 Valid 결과가 base보다 낮지 않아야 한다.
    - 같으면 α가 작은 쪽을 고른다.
- 고른 후보를 **V7**이라 부른다.
