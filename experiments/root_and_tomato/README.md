# 뿌리채소 "흙 묻음 vs 썩음"과 살짝 상한 토마토: 다시 학습 (채택 안 함, TV-12 그대로)

계획은 [PREREG.md](PREREG.md)에 결과를 보기 전에 적었다(덧붙임 1 포함).

## 무엇을 했나
- **사용자 요청 (2026-11-03):**
    - 감자·고구마·양파·대파는 흙 묻은 정상과 썩고 곰팡이 핀 것을 구분하게 한다.
    - 토마토는 아주 약간 상한 것도 "상함"으로 알아보게 한다.
    - 밭 사진은 하지 않는다.
- **다시 학습한 것:** CLIP 분류기와 새 채소 분류기. 채소 모델·판정 규칙·판단 보류는 그대로다.
- **B0′:** 작업 폴더를 잃어서 TV-12의 학습 사진 4,591/4,623장으로 같은 방법을 다시 돌렸다. 새 사진 없이 다시 만든 기준이다.

- **판정:** R1·R2 모두 조건을 어겨 T6로 가지 않았다. **TV-12를 그대로 쓴다. T6는 열지 않았다.**
- **흙 묻은 감자:** 효과가 있었다(45% → 60%).
    - 실제 장면 감자의 정상·상함 수를 맞추자(R2) 상한 감자 점수도 지켰다.
- **살짝 상한 토마토:** 효과가 거의 없었다(57% → 61%, +1장).
    - 실험실 사진(R1)만으로는 변화가 없었다.
    - 실제 곰팡이 토마토 62장을 더해도(R2) 1장 늘었다.
- **부작용:** 곰팡이 토마토를 많이 배우자 곰팡이 핀 과일을 "상한 채소"로 답하는 일이 늘었다(34 → 29).
    - 예전 K1·F1에서도 본 일이다. CLIP 특징에서 곰팡이 핀 과일과 채소가 가깝다.
- **다시 만들기만 해서 생긴 차이:** 예전 채소 → 새 채소 +1, 아시아 오이 −2 정도는 B0′에서도 생겼다.

- [`photos.py`](photos.py): 새 학습 사진을 공개 출처에서 다시 만든다.

- [`evaluate.py`](evaluate.py): 개발 사진 채점

- `head_features_f16.npz`: 학습 사진의 CLIP 특징(float16). 사진 없이 다시 학습할 수 있다.
- `dev_results_*.json`: 개발 결과(사진별 답 포함)
