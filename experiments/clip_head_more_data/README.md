# CLIP 분류기를 더 다양한 사진으로 다시 학습 (채택 안 함, 1장 차이)

지금 시스템이 인터넷 사진에서 가장 많이 틀리는 것은 상한 토마토다. 그래서 예전에 검수해 둔 휴대폰·밭 사진 등 1,168장을 CLIP 분류기 학습에만 더했다. 채소 모델은 그대로 두었다.

- **좋아진 것:** 인터넷 사진의 상한 토마토가 24장에서 30장으로 좋아졌다.
- **나빠진 것:** 과일을 거르는 수가 244장에서 233장으로 줄어, 미리 정한 기준(234장)에 1장 모자랐다.
- **판정:** 채택하지 않았다. Test는 채점하지 않았다.

## 한 일 (`PREREG.md`)

- **더한 사진:**
    - [more_data](../more_data/README.md)의 검수 사진 886장
    - [fix_carrot_cucumber](../fix_carrot_cucumber/README.md) K의 검수 사진 283장
        - 인터넷에서 모은 42장은 인터넷 채소 확인용 사진 점수를 부풀릴 수 있어 뺐다.
    - 확인용 사진과 같은 사진 1장(CLIP 특징 코사인 0.95 이상)을 빼서, 1,168장을 썼다.
- **학습:** CLIP 분류기를 Train 1,260장과 이 사진을 합친 2,428장으로 학습했다. 설정(C=10)은 지금과 같다.
- **다시 맞춘 값:** CLIP 분류기의 거르기 기준과 합친 온도는 지금과 같은 규칙으로 다시 맞췄다.

## 무엇을 배웠나

- **노린 약점은 좋아졌다.**
    - 밭에서 상한 토마토 사진이 들어가자, 인터넷 사진의 상한 토마토가 6장 더 맞았다.
    - 채소 모델을 다시 학습했던 예전 실험과 달리, Valid와 160장 시험지는 떨어지지 않았다.
- **대신 과일을 덜 거른다.**
    - 다양한 사진으로 배운 CLIP 분류기는 어떤 사진에도 덜 확신하게 되었다.
    - 같은 규칙(Valid와 실제 장면 채소의 95% 통과)으로 맞춘 거르기 기준이 −3.437에서 −3.705로 느슨해졌다.
    - 그래서 CLIP 분류기가 혼자 거르는 과일이 210장에서 192장으로 줄었다.
- **160장 시험지의 갈색 상한 오이(10장 중 8장 틀림)는 그대로였다.** 더한 사진에도 이런 오이는 거의 없다.
- 채소 쪽 이득(718장 중 +8장)과 과일 쪽 손해(374장 중 −11장)가 비슷한 크기라, 규칙대로 지금 시스템을 유지한다.
