# 대파 없애기: 8가지 → 7가지 채소 (G1, 반영 안 함)

계획과 개발 결과: [PREREG.md](PREREG.md). 사용자 결정(2026-11-03)으로 시도했다.

- **방법:** 새 채소 분류기만 다시 학습했다(`build.py`).
    - 대파 학습 사진 97장은 정답을 "모르는 것"으로 바꿔 가르쳤다.
    - 대파 두 칸은 학습하지 않은 클래스로 두었다.
- **개발 사진([dev_results.json](dev_results.json)):** 조건을 모두 지켰다.
    - 대파 33장 중 31장(94%)을 거른다. TV-12는 12%를 걸렀다.
    - 양파·고구마, 다섯 채소, 거르기는 TV-12와 같다.
- **블라인드 테스트셋 T6([기록](../../results/t6_test/README.md)):** 토마토 조각 검사와 합친 후보 G1C1로 채점했다. 걸러야 할 사진이 57 → 53/75로 줄어 조건(−3 이내)을 어겼다.
    - TV-12가 거른 썩은 과일 3장과 다른 채소 1장을 "상한 양파·상한 고구마"로 답했다. 정상 감자 1장도 "상한 고구마"로 답했다.
    - **추측:** 대파를 "모르는 것"으로 가르치고 기준을 다시 맞추면서, 새 채소 분류기의 거르기 기준이 −3.13에서 −2.03으로 느슨해졌다. 그래서 본 시스템이 거른 사진을 더 많이 가져간 것으로 보인다.
    - 개발 사진에서는 T3의 다른 채소 1장 정도로만 보였다.
- **판정:** 반영하지 않는다. TV-12(8종)를 그대로 쓴다.
