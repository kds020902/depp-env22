# 채소 놓치지 않기: 실제 장면 채소로 거르기 기준 다시 정하기 (채택)

"학습된 데이터가 아닙니다" 기준을 Valid만이 아니라 실제 장면 채소 사진으로도 맞췄다. 모델 가중치는 그대로이고 기준값 하나만 바뀌었다. 진짜 채소를 잘못 거르는 일이 줄었다. 대신 과일과 일상 사진은 덜 걸러진다. 사용자가 이 대가를 받아들이고 "채소 놓치지 않기"를 먼저 하기로 결정해 `model.pth`에 적용했다.

## 왜 바꿨나

- 예전 기준은 Valid 채소 300장 중 95%가 통과하는 값(−2.283)이었다.
- Valid는 학습 사진과 같은 데이터라 깨끗한 배경의 채소가 대부분이다. 실제로 찍은 채소는 점수가 조금 낮게 나와 많이 걸렸다.
    - 인터넷 채소 221장 중 50장(23%)을 걸렀다.
    - 부엌·시장·식탁에서 찍은 채소 192장 중 57장(30%)을 걸렀다.
- 실제 사용 환경에 가까운 사진으로 기준을 맞추는 방법(Bates et al. 2023)을 따랐다.

## 바꾼 것

- **기준:** Valid 300장과 LVIS 실제 장면 채소 192장을 합친 492장 중 95%가 통과하는 값이다. −2.283에서 **−1.962**로 바뀌었다.
- **LVIS 실제 장면 채소 192장 (`lvis_vegetables.csv`):**
    - [LVIS fruits-and-vegetables](https://www.kaggle.com/datasets/henningheyen/lvis-fruits-and-vegetables-dataset)(MIT)의 COCO 사진에서 채소 부분을 잘라냈다.
    - 잘라낸 700장을 모두 눈으로 보고 익히지 않은 채소만 남겼다. 당근 106장, 토마토 40장, 피망 16장, 오이 15장, 감자 15장이다.
    - 확인용 사진과 같은 사진은 없다. 채소 모델 학습에는 쓰지 않았다.
    - 이름표(종류·상태)는 쓰지 않는다. 기준을 정할 때 점수만 쓴다.
- **바꾸지 않은 것:** 모델 가중치, 온도(T=0.528), 점수 방식(energy)은 그대로다. 그래서 1등 클래스와 정확도는 바뀌지 않는다.
- **코드:** `src/calibrate.py`에 `--extra-photos` 옵션을 더했다. 이름표 없는 채소 사진 폴더를 주면 Valid와 합쳐 기준을 정한다.
- `model.pth`의 `unknown_check`에 예전 기준(`previous`)도 함께 적어 두었다. 되돌리려면 그 값을 `threshold`에 넣으면 된다.

## 순서

1. [논문 방법 실험](../posthoc_literature/README.md)의 탐색 결과를 보고 사용자가 "채소 놓치지 않기"를 먼저 하기로 결정했다.
2. Test를 채점하기 전에 바꿀 것과 적용 조건을 `PREREG.md`에 적었다.
3. Test 300장을 한 번 채점했다(`test_once.json`).

확인용 사진(인터넷 채소·과일·일상 사진)의 숫자는 결정 전에 이미 본 숫자다. 새로운 검증은 Test뿐이다.

## 해석

- **채소를 덜 놓친다.** 인터넷 채소에서 맞게 남긴 수가 20장 늘었고, Test에서도 잘못 거른 채소가 절반으로 줄었다.
- **과일은 거의 거르지 못한다.** 과일 4장 중 1장만 거른다. 원래도 채소와 닮은 과일은 잘 못 걸렀는데, 더 약해졌다. 데모의 과일 예시 5장도 모두 채소로 답한다.
- **일상 사진도 5장 중 1장은 채소로 답한다.** 예전에는 30장 중 1장꼴이었다.
- 같은 모델로는 "채소 남기기"와 "과일 거르기"를 함께 올릴 수 없다. 저울을 채소 쪽으로 옮긴 것이다. 둘 다 올리려면 과일과 채소를 구분할 수 있는 다른 특징(예: CLIP 문지기)이 필요하다.

## 다시 돌리기

```bash
python experiments/real_scene_threshold/crop_lvis.py lvis-fruits-and-vegetables-dataset.zip lvis_vegetables
python src/calibrate.py --model model.pth --extra-photos lvis_vegetables --extra-name "LVIS real-scene vegetable crops"
```

같은 192장이 픽셀 단위로 똑같이 만들어지고, 기준은 −1.962로 같게 나온다. Kaggle 압축 파일은 용량이 커서 올리지 않았다.
