# 실제 장면 채소로 거르기 기준 다시 정하기, Test 채점 전에 적음 (2026-10-11)

## 왜 하나

- 지금 `model.pth`(B)는 Valid 채소 300장 중 95%가 통과하는 값(−2.283)을 "학습된 데이터가 아닙니다" 기준으로 쓴다.
- Valid는 학습 사진과 같은 데이터라 깨끗한 배경의 채소가 대부분이다. 그래서 실제로 찍은 채소를 많이 거른다.
    - 인터넷 채소 221장 중 50장(23%)을 걸렀다.
    - 실제 장면 채소 192장(LVIS) 중 57장(30%)을 걸렀다.
- [논문 방법 실험](../posthoc_literature/README.md)의 탐색 결과(`explore.csv`)를 보고 사용자가 "채소를 놓치지 않기"를 먼저 하기로 결정했다. 과일·일상 사진이 덜 걸러지는 것은 받아들이기로 했다.
- 즉 이번 변경은 확인용 사진 결과를 이미 본 뒤의 결정이다. 확인용 사진 숫자는 새로운 검증이 아니다. 아직 보지 않은 것은 Test 300장뿐이다.

## 바꾸는 것 (이것만 바꾼다)

- **모델:** B 그대로다. 가중치와 온도(T=0.528)도 바꾸지 않는다. 그래서 1등 클래스와 정확도는 바뀌지 않는다.
- **점수:** energy 그대로다(−logsumexp(logit)).
- **기준:** Valid 300장과 LVIS 실제 장면 채소 192장(`lvis_vegetables.csv`)을 합친 492장 중 95%가 통과하는 값이다. 계산하면 −1.962다(지금 −2.283).
    - LVIS 192장은 부엌·시장·식탁을 찍은 COCO 사진에서 잘라낸 익히지 않은 채소다.
    - 700장을 눈으로 보고 골랐고, 확인용 사진과 같은 사진은 없다.
    - 채소 모델 학습에는 쓴 적이 없다(과일 문지기 3차 학습에만 썼다).
- 다른 비율(90%, 99%)이나 다른 점수는 시도하지 않는다.

## Test 채점 (한 번)

- 위 기준으로 Test 300장을 한 번 채점한다.
- 기준이 느슨해지기만 하므로 Test 정확도(275장)는 그대로이고, 맞게 남긴 수(지금 268장)는 줄어들 수 없다.
- 그래서 Test는 합격·불합격을 가르는 시험이 아니라 보고용이다. 다음을 적는다.
    - Test에서 거른 수(지금 10장)
    - 맞게 남긴 수
    - 새로 통과한 사진 중 맞게 답한 수와 틀리게 답한 수
- 적용은 사용자 결정대로 한다. 단, Test에서 새로 통과한 사진 중 틀린 답이 맞는 답보다 많으면 적용하지 않고 사용자에게 다시 묻는다.
