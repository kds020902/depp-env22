# 대파 정상·비정상 (진행 중)

TV-13은 대파의 종류만 판정한다. 상한 대파 학습 사진이 0장이라 두 번째 분류기의 `greenonion_rotten` 칸이 꺼져 있다.

## 0단계 (`prep.py`, `thresholds.json`)

상한 대파 사진 없이 할 수 있는 것만 했다. 정상 대파 117장(Train 97 + 새 채소 Valid 20)으로 기준선을 정했다.

- **zs (글 설명 점수):** CLIP ViT-B/16 사진 특징과 "시들고·물러지고·곰팡이 핀 대파" 문장들의 유사도에서 "싱싱한 대파" 문장들의 유사도를 뺀 값.
- **knn (정상과의 거리):** 정상 대파 학습 사진 중 가장 가까운 5장과의 코사인 거리. **배경·조명에도 반응하므로 검증 전에는 "이상 후보" 점수로만 본다**(Codex 지적).
- 기준선은 정상 117장의 95%가 정상으로 남는 값. **상한 대파를 얼마나 잡는지는 아직 측정하지 않았다.**

## 1단계: 상한 대파 사진 (사용자 촬영이 주 자료)

공개 사진은 Openverse·iNaturalist·Wikimedia Commons에서 사실상 0장이었다(2026-11-29 확인).

촬영 기록 규칙:
- 사진마다 **대파 단 번호**, 촬영일, 상태(정상 / 시듦·변색 / 물러짐 / 곰팡이)를 적는다.
- 보고할 때 **사진 장수와 서로 다른 대파 단 수를 함께** 적는다. 단 수가 적으면 독립된 사례가 적은 것이므로 결과는 **예비 검증**이라고 쓴다.
- 학습용·시험용은 **대파 단 단위로** 나눈다(같은 단이 양쪽에 들어가지 않게).

보조 자료(agy가 찾은 농업 병해 도감·보관 가이드 사진)는 라이선스 표기가 없거나 저작권이 있다.
쓰더라도 저장소에 사진을 올리지 않고 주소·해시만 기록하며, 밭에서 병든 대파는 부엌에서 상한 대파와 모습이 달라 따로 집계한다.

## 통합할 때 함께 볼 것 (Codex)

- 학습 자료뿐 아니라 `labels.UNTRAINED_CLASSES`, `NO_CONDITION_SPECIES`, 헤드의 `no_condition_species`·`untrained_classes` 설정.
- 공통 학습기(`src/train_new_veg_head.py`)는 Codex와 조율한 뒤에 바꾼다.
