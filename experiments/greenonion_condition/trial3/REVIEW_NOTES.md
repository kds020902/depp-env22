# 3차 검수 기록 (Codex 검수 반영)

- **실험 성격:** 2차의 단순 재실행이 아니라 **가중치를 바꾼 실험**이다(사용자가 2번 "설정 변경"을 고름). 바꾼 것은 상한 대파(15) 행 가중치 = 정상(14) 행 수 / 상한(15) 행 수 하나뿐이고, 후보는 하나만 돌렸다.
- **재현:** Codex가 저장된 5개 접힘 모델로 상한 48/64, 정상 39/59를 재현했다. 가중치는 각 접힘의 학습 행 안에서 계산되고, 평가 사진의 특징은 학습 입력에 없다. 무결성 검사 통과.
- **해석:** 상함 정답 37→48(+11), 정상 정답 49→39(−10). 130장 중 상태까지 맞힌 수는 86→87장이다.
  전체 판별력이 크게 좋아진 것이 아니라 **판단 기준이 상함 쪽으로 옮겨간 결과**로 본다.
- **G1:** 전체 969장 869→871(통과). 대파를 뺀 기존 7종은 855→854, 상한 고구마 18→17로 2차와 같다.
- **G2·G3:** 판단 보류된 사진도 포함한 값이며, 웹에 표시되는 성능이 아니다.
- **결론:** 개발 관문 통과와 채택은 구분한다. **추가 설정 조정은 여기서 멈춘다.** 최종 시험(37장)은 사용자가 품질 정리를 끝내고
  평가 기준을 고정한 뒤 별도로 한 번 연다. `model.pth`·`labels.py`·앱·배포는 바꾸지 않았다.
