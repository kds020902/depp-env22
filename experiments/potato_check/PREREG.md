# 흙 묻은 감자 다시 확인하기 (PC1): 계획 (후보를 만들기 전에 작성, 2026-11-23)

## 무엇을 묻나
- TV-12는 흙 묻은 정상 감자를 "상한 감자"로 답한다. T8에서 28장 중 2장만 맞혔고, 사용자 사진 2차에서는 26장 중 22장을 "상한 감자"로 답했다(19장은 확률 0.9 이상).
- 이 실수는 채소 모델(EfficientNet-B0)에서 나온다(`results/user_photos_2/stages.json`).
- **질문:** "상한 감자"라는 답만 CLIP 분류기에 한 번 더 물어보면, 흙 묻은 정상 감자를 되찾으면서 진짜 상한 감자를 놓치지 않을 수 있는가?
- 순서는 Codex의 제안을 따랐다(`docs/codex_handoff.md` 2026-11-23: 감자 먼저, 고구마는 뒤에 따로).

## 바꾸는 것 (변수 하나)
- **PC1:** 다섯 채소 시스템이 "상한 감자"로 답한 사진에 대해서만, 다섯 채소용 CLIP 분류기 혼자 본 "정상 감자 : 상한 감자" 비율을 본다. **정상 감자 쪽이 0.5 이상이면 답을 "정상 감자"로 바꾼다.**
    - 보여 주는 확률은 그 비율이다. 0.9 미만이면 지금처럼 판단 보류로 보인다. 즉 CLIP 분류기가 0.9 이상 확신할 때만 "정상 감자"가 확정 답으로 나온다.
    - 구현: `src/decision.py`의 `apply_potato_check()`. 체크포인트에 `potato_check`가 있을 때만 돈다. TV-12에는 없으므로 TV-12의 답은 바뀌지 않는다.
- **고정:** 모든 가중치, 거르기 기준, 새 채소 분류기와 전환 기준 0.8, 판단 보류 0.9. 새 채소 분류기가 답한 사진(양파·고구마·대파)과 거른 사진은 건드리지 않는다.
- **기준 0.5의 근거:** 맞춘 값이 아니라 "CLIP 분류기가 두 감자 클래스 중 정상을 더 그럴듯하게 본다"는 뜻의 자연스러운 값이다.

## 이미 본 것 (탐색, 숨기지 않고 적는다)
- 기준을 정하려고 개발 세트(저장된 969장 + 라벨 없는 966장)에서 TV-12가 "상한 감자"로 답한 183장의 비율을 봤다.

| 기준 | 흙 묻은·정상 감자 26장 중 바뀜 | 진짜 상한 감자 126장 중 바뀜 |
|---|---:|---:|
| 0.107 (상한 감자의 95%가 남는 값) | 21 | 7 |
| 0.169 (98%) | 17 | 3 |
| **0.5** | **10** | **0** |
| 0.9 | 3 | 0 |

- 낮은 기준이 더 많이 되찾지만 상한 감자를 정상으로 돌린다(가장 나쁜 실수). 그래서 0.5를 골랐다.
- 이 개발 세트의 결과는 기준을 고를 때 이미 봤으므로 **증거로 세지 않는다.** 안전 확인으로만 쓴다.

## 확인 순서
### 1) 안전 확인: 이미 본 개발 세트 (`tools/compare_on_dev.py`)
| 조건 (TV-12 대비) | 기준 |
|---|---|
| 상함 → 정상 오류 (어느 채소든, 385장) | +1장 이내 |
| 다섯 채소 맞은 수 (827장) | TV-12 이상 |
| 라벨 없는 사진(과일·일상·실제 장면 966장)의 답이 바뀐 수 | 3장 이내 |

### 2) 처음 대 보는 개발 사진: 사용자 사진 2차의 채점 대상 41장
- PC1은 이 사진을 아직 보지 않았다. TV-12와 SP1의 답은 봤다(TV-12: 흙 묻은 감자 26장 중 4장 맞음, 22장 "상한 감자").

| 조건 (TV-12 대비) | 기준 |
|---|---|
| 흙 묻은 정상 감자 26장 중 맞은 수 | **+5장 이상** (4 → 9장 이상) |
| 상한 고구마 15장을 어느 채소든 "정상"으로 답한 수 | +1장 이내 (TV-12는 0장) |

- 1)과 2)를 모두 지키면 T9로 간다. 하나라도 어기면 T9를 열지 않고 "반영 안 함"으로 끝낸다.

### 3) 블라인드 시험지 T9 (한 번만 채점)
- 주 판정은 T8과 같은 사진으로 확인된 1장(`t9-sweetpotato_rotten-15`)을 뺀 **89장**으로 한다(상한 고구마 29, 상한 감자 30, 흙 묻은 정상 감자 30). 90장 전체의 수도 함께 적는다. 근거는 `results/t9_test/RULES.md` 덧붙임 3에 적는다.

| "채택을 제안한다"의 조건 (TV-12 대비, 모두 만족) | 기준 |
|---|---|
| 흙 묻은 정상 감자 30장 중 맞은 수 | **+6장 이상** (+20%포인트) |
| 상한 감자 30장 중 맞은 수 | −2장 이내 |
| 상한 사진 59장을 어느 채소든 "정상"으로 답한 수 | +2장 이내 |
| 〃 그중 확정 답(0.9 이상)으로 나온 수 | TV-12 이하 |
| 89장 중 맞은 수 | +3장 이상 |

- 조건을 만족해도 채택은 사용자가 결정한다. T9 채점은 사용자의 진행 지시를 받은 뒤에 한다.
- 함께 보고할 것: 판단 보류 수, 같은 사진의 맞음 ↔ 틀림, 감자 클래스별 오판, 상한 고구마의 답 분포.

## 예상 (추측)
