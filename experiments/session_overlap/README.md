# Train–Test 같은 촬영 세션 겹침 (측정)

전문가 점검 3번: Test 사진 중 Train과 같은 촬영 세션에서 나온 사진을 찾고, 그 사진을 뺀 정직한 Test 점수를 냈다. 규칙은 결과를 보기 전에 [`PREREG.md`](PREREG.md)에 적었다. 모델은 바꾸지 않았다. 이미 채점한 V7의 Test 답을 나눠서 본 것이라 새 채점이 아니다.

**결론:**
- Test 300장 중 **19장(6%)** 이 Train과 같은 세션이었다. V7은 이 19장을 모두 맞혔다.
- 이 19장을 빼도 점수는 거의 그대로다. 맞게 남긴 비율이 95.0%에서 94.7%가 된다.
- 워터마크 사진까지 빼면 94.2%다.
- 지금 Test 점수는 세션 겹침 때문에 크게 부풀지 않았다.

## 찾은 방법

1. **후보:** Test 300장마다 학습 사진 중 CLIP 유사도가 가장 높은 사진을 찾았다.
    - 학습 사진: 채소 모델의 Train 1,260장 + CLIP 분류기 추가 사진 4,623장
    - 0.88 이상인 120장을 후보로 했다.
2. **확인:** 후보는 가장 닮은 학습 사진 두 장과 나란히 놓고 눈으로 봤다.
3. **기준 아래 확인:** 0.85~0.88 사이에서 무작위 20쌍을 더 봤다. 같은 세션은 1쌍이었다. 미리 정한 대로(2쌍 이상이면 기준을 낮춤) 기준은 그대로 두었다.
4. **"같은 세션"의 정의:** 같은 채소 개체를 다시 찍었거나, 같은 배경·소품 위의 같은 채소(또는 같은 화분)를 배치·각도만 바꿔 찍은 사진이다. 분위기만 비슷한 흰 배경 스톡 사진은 넣지 않았다.

**찾은 19장 (`same_session.csv`)**

| 클래스 | 장 | 예 |
|---|---:|---|
| 감자 정상 | 5 | 파란 배경·베이지 배경의 같은 감자들, 흰 종이 위 같은 감자 |
| 오이 비정상 | 3 | 같은 상한 오이의 스톡 사진(alamy, shutterstock 연속 번호), 같은 밭의 병해 사진(bugwood 연속 번호) |
| 당근 비정상 | 3 | 같은 곰팡이 당근, 같은 그물망 속 당근 |
| 오이 정상 | 2 | 같은 시장에서 손에 든 오이, 같은 꽃·잎과 함께 찍은 오이 |
| 감자 비정상 | 2 | 파란 장갑에 든 같은 감자, 같은 곰팡이 감자(alamy) |
| 토마토 정상 | 2 | 같은 텃밭의 같은 토마토 포기 (벽·기둥이 같음) |
| 토마토 비정상 | 2 | 배경만 바꿔 다시 찍은 같은 토마토 |
| 피망(정상·비정상), 당근 정상 | 0 | |

- 19장 모두 가장 닮은 사진은 채소 모델의 Train에 있었다.
- 데이터셋을 만들 때 쓴 ResNet18 유사도(0.92)로는 잡히지 않았다. 배경이나 배치가 바뀌면 같은 개체라도 유사도가 크게 떨어진다.
- 검토한 140장과 판정은 `reviewed.csv`에 있다.

## 결과 (V7, Test)

| Test 묶음 | 장 | 정확도 | 맞게 남긴 수 (95% 신뢰구간) | 채소 모델만 | CLIP 분류기만 |
|---|---:|---:|---:|---:|---:|
| 전체 | 300 | 288 (96.0%) | 285 (95.0%, 91.9~96.9) | 275 (91.7%) | 286 (95.3%) |
| 같은 세션 사진을 뺀 나머지 | 281 | 269 (95.7%) | **266 (94.7%, 91.4~96.7)** | 256 (91.1%) | 267 (95.0%) |
| 같은 세션과 워터마크 사진을 모두 뺀 나머지 | 208 | 198 (95.2%) | **196 (94.2%, 90.2~96.7)** | 190 (91.3%) | 195 (93.8%) |
| 같은 세션 사진만 | 19 | 19 | 19 | 19 | 19 |

- **세션 겹침이 점수에 준 영향은 작다.** 0.3%p 정도이고, 신뢰구간(±3%p)보다 훨씬 작다.
- **같은 세션 사진은 쉬운 문제였다.** 19장 모두 채소 모델 혼자서도 맞혔다. 사진 수가 적어서 전체 점수에는 영향이 작다.
- **워터마크 사진까지 빼면 0.8%p 더 내려간다.** 워터마크가 있는 81장에서는 맞게 남긴 수가 78장(96.3%)으로 조금 더 높았다([watermark](../watermark/README.md)).

## 한계

- 0.85 아래 사진은 보지 않았다. 0.85~0.88 구간 62장 중 20장을 봐서 1장이 나왔으므로, 이 구간에 2장쯤 더 있을 수 있다.
- Valid는 이번에 보지 않았다. Valid는 모델 고르기와 보정에만 쓰므로, 겹침이 있으면 Valid 점수가 조금 높게 나올 수 있다.
- 새 인터넷 시험지(241장)는 올린 사람 단위로 나눠서 만들었으므로 이 문제가 거의 없다. Test보다 그 점수(83%)가 실제 사진 성능에 더 가깝다.

## 파일

- `same_session.csv`: 같은 세션 19장과 가장 닮은 학습 사진
- `reviewed.csv`: 눈으로 본 140장과 판정
- `find_pairs.py`: 검토용 비교 그림을 만든 스크립트 (기록용)
- `score.py`: 위 표를 다시 계산하는 스크립트 (작업 폴더의 Test 특징 사용)
