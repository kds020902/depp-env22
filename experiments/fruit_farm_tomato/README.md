# CLIP 분류기에 농가 토마토와 (상한) 과일 가르치기 (후보 F, 채택 안 함)

교수님 피드백("아무 사진을 넣어도 결과가 잘 나와야 한다")과 상한 토마토 문제를 함께 고치려고, CLIP 분류기 학습 사진을 더했다. 미리 정한 기준을 넘지 못해 `model.pth`는 그대로다. 단, "아무 사진" 시험지에서는 크게 좋아져서 채택 여부를 사용자가 정하도록 남겨 두었다.

## 왜 했나

- **아무 사진:** 거르지 못한 과일 대부분이 상한 사과·망고·레몬이고, "상한 감자"나 "상한 토마토"로 답했다.
    - 인터넷 과일에서는 통과한 37장 중 29장이었다.
    - Kaggle 과일에서는 통과한 116장 중 90장이었다.
- **상한 토마토:** [fusion_weight](../fusion_weight/README.md)에서 채소 모델 비중을 낮추지 못한 원인은, CLIP 분류기가 천 위의 덜 익은 정상 토마토를 상했다고 보는 것이었다.

## 바꾼 것 (`PREREG.md`, `added_photos.csv`)

| 더한 사진 | 장 수 | 쪽 |
|---|---:|---|
| Mendeley 농가 토마토 (나무 판 위, 휴대폰) 정상 / 상함 | 105 / 107 | 채소 (정상·상한 토마토) |
| Kaggle 과일 (사과·바나나·망고·오렌지·딸기, 대부분 상함) | 527 | 다섯 채소가 아님 |
| iNaturalist 상한 과일 (학습 쪽 관찰자) | 184 | 다섯 채소가 아님 |
| Openverse 상한 과일 (학습 쪽 올린 사람) | 50 | 다섯 채소가 아님 |

- 모두 눈으로 검수했다. 토마토·감자·오이·피망·당근일 수 있는 사진은 뺐다.
- 확인용 사진과 새 "아무 사진" 시험지의 복사본(CLIP 코사인 0.95 이상)은 학습 전에 뺐다.
- 채소 모델, 분류기 설정(C=10, 11클래스), 거르기 규칙(R1)은 그대로다.
- **F1:** 두 모델을 지금처럼 1:1로 합친다.
- **F2:** 채소 모델 비중을 W와 같은 방법으로 다시 정한다(w = 0.05가 나왔다).

## 결과

**개발용 확인 (`check_results.json`): 둘 다 탈락**

| | 지금 | F1 | F2 |
|---|---:|---:|---:|
| 인터넷 과일 374장 거름 | 337 (90%) | **359 (96%)** | 359 |
| Kaggle 과일 400장 거름 (더한 과일과 같은 데이터) | 284 (71%) | 390 (98%) | 390 |
| 인터넷 채소 221장 맞게 남긴 수 (기준 188) | 190 | **184 ✗** | 193 |
| 160장 시험지 정확도 (기준 148) | 150 | 150 | **129 ✗** |

- F1은 상한 과일을 배운 대신 상한 채소도 더 걸렀다. 인터넷 채소에서 상한 감자 8장, 상한 토마토 3장이 늘었다.
- F2는 농가 토마토를 더해도 160장 시험지의 정상 토마토가 13/20으로 여전히 틀렸다. 더한 토마토는 빨갛게 익은 것이 대부분이라, 덜 익은 주황색 토마토와 달랐다.

**사용자 결정 뒤 F1 마지막 채점 (`final_once.json`, 한 번씩)**

사용자가 F1의 맞바꿈을 봉인 시험지로 확인하기로 했다. 개발용 확인만 건너뛰고, 미리 정한 채택 조건을 그대로 썼다(`PREREG.md` 끝 덧붙임).

| | 지금 시스템 | F1 | 채택 조건 |
|---|---:|---:|---|
| 새 인터넷 시험지 241장 정확도 | 203 | 203 | 203 이상 ✓ |
| 새 인터넷 시험지 맞게 남긴 수 | 193 | **187** | 191 이상 ✗ |
| Test 300장 정확도 / 맞게 남긴 수 | 288 / 285 | 288 / 285 | 286 / 283 이상 ✓ |
| ["아무 사진" 시험지](../../results/10class/anyphoto_test/README.md) 255장 좋은 답 | 210 (82%) | **237 (93%)** | 지금 + 8 이상 ✓ |
| 그중 상한 과일 50장 | 24 | **48** | |
| 그중 일상 장면 속 다섯 채소 22장 | 20 | 21 | 지금 − 2 이상 ✓ |

- 판정: 새 인터넷 시험지 맞게 남긴 수가 4장 모자라 **채택하지 않았다**.
- 맞바꿈: F1은 아무 사진에서 27장을 더 알맞게 답하는 대신, 처음 보는 인터넷 채소 241장 중 6장을 더 "학습된 데이터가 아닙니다"로 거른다. 틀린 답의 수(34장)는 같다.
- 새 인터넷 시험지는 세 번째, Test는 여덟 번째 채점이다. "아무 사진" 시험지는 처음 썼다.

`evaluate.py`와 `final.py`는 작업 폴더의 경로를 그대로 담고 있어서 기록용이다.
