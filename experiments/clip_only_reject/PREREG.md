# 거르기를 CLIP 기준 하나로, 마지막 채점 전에 적음 (2026-10-29)

## 왜 하나

- 지금 시스템(N3)은 두 모델 중 하나라도 "학습한 채소가 아니다"라고 보면 "학습된 데이터가 아닙니다"로 거른다.
    - 채소 모델(B): energy 점수 > −1.962
    - CLIP 분류기: "다섯 채소가 아님" 로그 오즈 > −0.604
- 새 인터넷 시험지에서 진짜 채소의 20%(49/241)를 걸렀다. 인터넷 채소 221장에서 거른 28장 중 19장은 채소 모델의 기준 때문이었다.
- 채소 모델의 기준은 CLIP 분류기가 "다섯 채소가 아님"을 배우기 전에 만들었다. 지금은 CLIP 쪽이 과일·일상 사진을 거의 다 거르므로, 채소 모델의 기준은 진짜 채소만 더 거르는 것으로 보인다.

## 후보 R1 (하나만, 지금 고정)

- "학습된 데이터가 아닙니다"는 **CLIP 분류기의 "다섯 채소가 아님" 로그 오즈 > −0.604일 때만** 답한다.
- 채소 모델의 energy 기준은 쓰지 않는다.
    - 단, CLIP을 쓰지 않는 설정(`--no-clip`, 데모의 빠른 분석)은 지금처럼 채소 모델 기준으로 거른다.
- 다시 학습하거나 다시 맞추는 값은 없다.
    - CLIP 기준값은 지금과 같다. 이미 Valid + 실제 장면 채소 192장의 95%가 통과하도록 맞춘 값이다.
    - 10개 클래스 확률과 판정은 바뀌지 않는다. 바뀌는 것은 거르느냐 마느냐뿐이다.
