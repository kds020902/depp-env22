# 거르기를 CLIP 기준 하나로 (R1 채택)

"학습된 데이터가 아닙니다"로 거르는 규칙만 바꿨다. 모델 가중치, 확률, 10개 클래스 판정은 그대로다.

- **전 (N3):** 두 모델 중 하나라도 학습한 채소가 아니라고 보면 거른다.
    - 채소 모델: energy 점수 > −1.962
    - CLIP 분류기: "다섯 채소가 아님" 로그 오즈 > −0.604
- **후 (R1):** CLIP 분류기의 "다섯 채소가 아님" 로그 오즈 > −0.604일 때만 거른다.
    - CLIP을 쓰지 않는 설정(`predict.py --no-clip`, 웹 데모의 빠른 분석)은 지금처럼 채소 모델 기준으로 거른다.

## 왜 했나

- [과대·과소적합 점검](../../results/10class/system_checks/README.md)에서, 인터넷 채소 221장 중 진짜 채소를 거른 28장 가운데 19장이 채소 모델의 기준 때문이었다.
- 채소 모델의 기준은 CLIP 분류기가 "다섯 채소가 아님"을 배우기 전에 만들었다. 지금은 CLIP 쪽이 과일·일상 사진을 거의 다 거르므로, 채소 모델의 기준은 진짜 채소를 더 거르기만 했다.

## 결과 (`final_once.json`, 마지막 채점은 한 번씩)

| | N3 | **R1 (지금)** |
|---|---:|---:|
| **새 인터넷 시험지 241장 맞게 남긴 수** | 169 | **193** |
| 그중 거른 진짜 채소 | 49 (20%) | **14 (5.8%)** |
| 거르지 않았지만 틀린 수 (틀린 답을 보여 줌) | 23 | 34 |

| **Test 300장 맞게 남긴 수** | 282 | **285** |
| Test에서 거른 수 | 9 | 4 |
| 인터넷 과일 374장 중 거른 수 (개발용) | 347 (93%) | 337 (90%) |
| 일상 사진 400장 중 거른 수 (개발용) | 400 | 400 |
| 인터넷 채소 221장 맞게 남긴 수 (개발용) | 175 | 190 |

- **채택 기준** (`PREREG.md`): 셋 다 넘었다.
    - 새 시험지 맞게 남긴 수 172 이상
    - 틀린 답 증가(+11)가 맞게 남긴 수 증가(+24)보다 적을 것
    - Test 맞게 남긴 수 282 이상
- 새 시험지에서 많이 거르던 상한 토마토는 22장에서 1장으로, 정상 당근은 9장에서 4장으로 줄었다.

## 미리 밝힌 점

- 개발용 사진의 숫자는 이 후보를 정하기 전에 이미 봤다. 그래서 판단은 새 시험지와 Test로만 했다.
- 새 시험지는 이번이 두 번째 후보 채점(첫 번째는 N3), Test는 일곱 번째 채점이다.
- 거르는 사진이 줄어든 만큼, 틀린 답을 그대로 보여 주는 사진은 늘었다(새 시험지 23 → 34장). "모르겠다"고 답하던 사진 일부가 틀린 답으로 바뀐 것이다.

## 다시 돌리기

`model.pth`의 `clip_head.vegetable_model_check`가 `false`이면 이 규칙을 쓴다. 분류기를 새로 만들 때는 `src/train_clip_head.py ... --clip-check-only`를 붙인다. `final.py`는 작업 폴더의 경로를 그대로 담고 있어서 기록용이다.
