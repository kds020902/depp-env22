# 틀린 이유 두 가지 고쳐 보기: 계획 (결과를 보기 전에 적음, 2026-11-03)

## 배경
Test 300에서 틀린 15장을 이유별로 나눴다. 가장 큰 두 덩어리를 고쳐 본다(사용자 요청: 바로 바꾸지 말고 해 본 뒤 차이를 보여 줄 것).
- **1번, 모양보다 색·질감을 봄 (4장):** 곰팡이 핀 피망을 "상한 토마토", 주황 오이를 "상한 감자"로 본다.
- **2번, 작은 부분을 놓침 (5장):** 멀쩡한 것들 사이의 상한 하나, 작은 싹, 작은 반점을 놓친다.

## 후보 A: 종류는 모양으로 (CLIP 글 설명을 종류에만)
- 다섯 채소 확률 P(10칸)에 채소별 CLIP 글 설명 확률 Z(종류)^β를 곱하고 다시 합이 1이 되게 한다. Z는 V7의 10개 클래스 글 설명으로 zero-shot 확률을 낸 뒤 종류별로 더한 값이다(새 문장을 만들지 않는다).
- 같은 종류 안에서 정상:상함 비율은 바뀌지 않는다. 거르기와 새 채소 분류기는 그대로다.
- 후보: β = 0.25, 0.5, 1.0
- **고르는 규칙:** Valid 300 + 바깥 개발용(인터넷 221, 160장, 아시아 오이 37)에서 맞게 남긴 수의 합이 가장 큰 β. TV-12보다 +3장 이상이 아니면 "효과 미미"로 적는다.

## 후보 B: 작은 상한 부분 경보 → 판단 보류
- 사진마다 조각 5개(네 모서리와 가운데, 가로·세로 2/3)를 본다(experiments/improve_without_photos와 같은 조각).
- 시스템이 "정상 X"로 답하려 할 때, 어느 조각에서든 CLIP 분류기의 "상한 X / (정상 X + 상한 X)"가 t 이상이면 답하지 않고 판단 보류로 돌린다. 답을 상함으로 바꾸지는 않는다.
- 후보: t = 0.8, 0.9, 0.95
- **고르는 규칙:** 바깥 개발용에서 "답한 사진 중 상함을 정상이라고 한 수"가 가장 적은 t. 단, 답한 비율이 TV-12(판단 보류 0.9)보다 5%p 넘게 줄면 그 t는 쓰지 않는다.

## 확인 사진과 보고
- 고르는 데는 Valid와 바깥 개발용만 쓴다.
- Test 300은 사용자가 틀린 사진을 이미 봤으므로 블라인드가 아니다. 참고로 함께 보고한다.
- T3·T4·새 인터넷 241은 쓰지 않는다.
- 보고 내용:
    - 맞게 남긴 수(판단 보류 없이)
    - 판단 보류(0.9)를 켰을 때의 답한 비율, 답한 사진의 정답률, 자신 있게 틀린 수, 상함을 정상이라고 한 수
    - 답이 바뀐 사진 예시
- 채택(모델·predict.py 반영)은 사용자가 결과를 보고 정한다.
