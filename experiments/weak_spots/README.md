# 약점 사진으로 CLIP 분류기 다시 학습 (채택 안 함)

인터넷 사진에서 틀리는 종류(밭에서 아래가 썩은 초록 토마토, 싹 난 감자, 흙 묻은 정상 감자·당근)의 사진을 모아 CLIP 분류기 학습에 더했다. 채소 모델은 그대로 두었다. 기준은 결과를 보기 전에 `PREREG.md`에 적었다.

- **좋아진 것:** 인터넷 채소 221장 정확도가 190장에서 W1 194장, W2 199장으로 올랐다.
- **나빠진 것:** 과일·일상 사진을 덜 걸렀다.
- **판정:** 두 후보 모두 채택하지 않았다. 새 시험지와 Test는 후보로 채점하지 않았다.
- 이 실패 원인을 고친 것이 [not_five_class](../not_five_class/README.md)이고, 그 실험은 채택됐다.

## 더한 사진 (434장, `added_photos.csv`)

- **jimpax/datasetv13 (CC BY 4.0)의 카메라 사진 390장**
    - 배꼽썩음병 토마토 262장
    - 밭의 정상 토마토 128장
    - 빠진 사진: 예전 실험에서 쓴 사진과 거의 같은 사진 84장, 서로 거의 같은 사진, 썩은 곳이 안 보이는 25장
- **Openverse 학습 쪽 사진 44장:** 새 인터넷 시험지와 올린 사람이 다르다.
- 확인용 사진과 같은 사진(CLIP 코사인 0.95 이상)은 없었다.

## 무엇을 배웠나

- [clip_head_more_data](../clip_head_more_data/README.md)와 같은 현상이 다시 나왔다.
    - 다양한 사진으로 배운 CLIP 분류기는 어떤 사진에도 덜 확신한다.
    - 그래서 "얼마나 확신이 없는가"(energy)로 맞춘 거르기 기준이 느슨해진다(−3.44 → W2 −3.88).
    - 채소를 더 맞히는 만큼 과일·일상 사진을 덜 거른다.
- 사진만 더해서는 이 맞바꿈을 벗어나기 어렵다. 그래서 "채소가 아님"을 직접 가르치는 방법을 시험했다.
- 이 실험 중에 새 인터넷 시험지 241장을 만들었고, 지금 시스템을 한 번 채점해 두었다(191장, 79.3%, [outside_test2](../../results/10class/outside_test2/README.md)).

`evaluate.py`는 작업 폴더의 경로를 그대로 담고 있어서, 기록용으로만 남긴다.
