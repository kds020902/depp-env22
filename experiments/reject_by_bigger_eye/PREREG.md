# 판정은 TV-12, 거르기만 큰 이미지 모델: 계획 (결과를 보기 전에 적음, 2026-11-03)

## 배경
- 블라인드 시험지 T3·T4·T5에서 TV-12가 되풀이해 틀린 곳 중 하나는 **상한 과일을 "상한 감자"로 답하는 것**이다. 83장 중 33장이었다. 걸렀어야 하는 사진이다.
- [bigger_eye](../bigger_eye/README.md)의 큰 이미지 모델은 거르기는 세 번 모두 더 잘했다.
    - 개발: 상한 과일 761장 중 L1 635, B1 600, TV-12 534
    - T3+T4: 걸러야 할 사진 100장 중 L1 77, TV-12 60
    - T5: 63장 중 L1 51, TV-12 42
- 하지만 L1에 판정까지 맡기자 T5에서 다섯 채소 정답이 줄었다(58 → 55).
- 그래서 **채소 종류·상태 판정은 TV-12 그대로 두고, "학습된 데이터가 아닙니다"로 거를지만 큰 모델의 분류기에 맡긴다.**
- 이 후보는 약점 2(상한 과일)만 노린다. 약점 1(정상 감자 → 상한 감자)과 약점 3(상한 토마토 → 정상)은 고치지 않는다. 판정을 바꾸지 않으므로 이 두 약점은 TV-12와 같아야 한다.
- 이 아이디어는 T3·T4·T5의 결과를 본 뒤에 나왔다. 그래서 공정한 확인은 아직 쓰지 않은 블라인드 테스트셋 [T6](../../results/t6_test/RULES.md)로만 한다.

## 후보 (새로 학습하지 않음)
bigger_eye에서 TV-12와 같은 사진·규칙으로 이미 만든 CLIP 분류기를 거르기에만 쓴다.
- 거르기 기준은 그때 같은 규칙으로 정했다. Valid와 실제 장면 채소 192장의 95%가 통과하도록 맞췄다.
- 글 설명 거르기(α 0.25)도 포함한다.

| 이름 | 거를지 정하는 것 | 웹 데모 |
|---|---|---|
| R-B1 | B1(SigLIP2-B/16)의 거르기 | 됨 |
| R-L1 | L1(SigLIP2-L/16)의 거르기 | 안 됨 (PC용만) |
| R-B1∪ | TV-12 또는 B1이 거르면 거름 | 됨 |
| R-L1∪ | TV-12 또는 L1이 거르면 거름 | 안 됨 |

- **판정:** 다섯 채소 확률은 TV-12 그대로다(채소 모델 + B/16 CLIP 분류기).
- **새 채소:** 양파·고구마·대파 분류기도 TV-12 그대로다(B/16 특징, τ 0.8). 새 채소 분류기가 "거른 사진을 새 채소로 살리는" 규칙도 그대로 쓴다. 거른 사진이 무엇인지만 후보의 결정을 따른다.
- **판단 보류(0.9):** 그대로다.
- 개발용 확인은 이미 뽑아 둔 특징(`eye_B1_feats.npz`, `eye_L1_feats.npz`)으로 한다. 모델을 다시 내려받을 필요가 없다.

## 개발 사진으로 고르기
**지키는 조건 8개** (experiments/t3_weak_spots와 같다):
- 맞게 남긴 수: Valid −3 이내, 인터넷 221 −3 이내, 160장 −3 이내, 아시아 오이 −2 이내
- 일상 사진 400장 거름: −5 이내
- 새 채소 Valid: −2 이내
- 옛 채소 개발 사진이 새 채소로 바뀌는 수: +1 이내
- 약점 개발 사진의 짝 클래스: −2 이내

**개선의 기준:** 상한 과일 761장에서 거른 수가 TV-12보다 **38장(5%p) 이상** 많다.

**고르는 규칙:**
1. 조건 8개를 모두 지키고 개선의 기준을 넘은 후보 중, 상한 과일 761장을 가장 많이 거른 후보를 고른다.
2. 단, 웹 데모에 넣을 수 있는 후보(R-B1, R-B1∪)가 그 후보보다 15장 이내로 뒤지면 그쪽을 고른다.
3. 기준을 넘은 후보가 없으면 "효과 없음"으로 적고 T6는 쓰지 않는다.

**같이 보고할 것:**
- Valid+바깥 718장 맞게 남김
- 과일 374장 거름, 약점 개발 사진의 상한 과일 30장 거름
- 판단 보류를 켰을 때의 답한 수·자신 있게 틀린 수
- Test 300 (참고, 블라인드 아님)

## T6 채택 조건 (T6를 열기 전에 정함)
고른 후보와 TV-12를 T6(175장)로 한 번씩 채점한다. 아래를 모두 지키면 반영을 제안한다.
- **약점 2:** 상한 과일 40장 중 거른 수가 TV-12보다 **4장 이상** 많다.
- **다섯 채소 맞게 남김(97장):** TV-12보다 −2 이내다. 판정이 같으므로, 줄어든다면 채소를 잘못 거른 경우다.
- **정상 과일·닮은 다른 채소 35장 거름:** TV-12보다 −2 이내다.
- **새 채소 종류 맞히고 안 거름(3장):** TV-12보다 −1 이내다.
- 약점 1·3과 상한 토마토의 데이터셋/인터넷 나눔은 보고만 한다.
- 반영은 사용자가 정한다. 반영하면 `model.pth`에 거르기용 분류기를 따로 넣고, `predict.py`가 두 번째 이미지 모델을 불러오도록 고쳐야 한다(B1이면 웹 데모도 바꿀 수 있다).

## T6를 쓰는 시점
- T6는 한 번만 쓴다. 약점 1을 고치는 후보를 따로 시도한다면, 그 후보를 개발 사진으로 고른 뒤 이 후보와 묶어서 함께 채점할지 사용자가 정한다.
- 정하기 전에는 T6를 열지 않는다.
