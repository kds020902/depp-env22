# 채소 판별 데모 UI·UX 변경 내역

Claude의 첫 Gradio 화면(`7262a84`)을 기준으로, Codex가 바꾼 화면과 사용 흐름을 정리했다. 화면 개편은 `ec3713c`, 버튼 크기와 상세 결과 수정은 `852b78e`에 들어 있다.

## 화면과 사용 흐름

| 항목 | Claude 초안 | Codex 최종본 |
| --- | --- | --- |
| 첫 화면 | 제목과 소개 문단에 판정 대상 8종을 함께 적었다. | 진한 녹색 상단에 **채소 상태 판별** 제목을 두고, 판정 대상 8종을 별도 목록으로 보여 준다. |
| 화면 배치 | Gradio 기본 스타일의 입력·결과 두 열을 사용했다. | 아이보리 바탕에 **사진 올리기**와 **판정 결과**를 카드로 나눴다. 데스크톱에서는 나란히, 690px 이하에서는 위아래로 배치한다. |
| 사진 입력 | 사진을 올리면 자동 판정했고, 버튼으로도 판정할 수 있었다. | 사진을 고르면 미리보기와 준비 안내를 먼저 보여 준다. 사용자가 **판정하기**를 눌러야 판정을 시작한다. 업로드 영역 아래에 JPG·PNG와 20MB 제한을 표시한다. |
| 판정 버튼 | Gradio 기본 버튼을 사용했다. | 버튼 높이를 **48px**로 고정했다. 기준 폭은 **405px**이고 좁은 화면에서는 카드 폭을 넘지 않는다. 결과 영역이 길어져도 버튼 높이는 48px이다. |
| 처리 중·입력 변경 | 업로드나 버튼 클릭이 곧바로 같은 판정 함수를 호출했다. | 판정 중에는 진행 안내를 표시하고 사진 입력과 버튼을 잠시 비활성화한다. 사진을 바꾸거나 지우면 이전 결과와 위치 지도를 지운다. |
| 판정 전 | 결과 영역에 “사진을 올려 주세요.”를 표시했다. | 결과 카드에 **“아직 판정 전이에요...”**를 표시하고, 상세 영역에 **“야채 판정을 해주세요 ┄ N%”**를 네 줄 보여 준다. |
| 판정 상세 | 확률 목록과 위치 지도 컴포넌트를 결과 아래에 배치했다. | **판정 상세 보기**를 접을 수 없는 영역으로 만들었다. 확률 정보가 있으면 가까운 답 최대 5개를 표시하고, 모델이 위치 지도를 반환할 때 함께 보여 준다. 확률이 없는 결과에는 별도의 안내를 표시한다. |
| 사용 안내 | 판정 기준과 한계를 화면 맨 아래에 펼쳐 놓았다. | 식용 여부에 관한 안내는 화면에 바로 보이게 두고, 나머지는 **판정 기준과 한계**에서 펼쳐 볼 수 있게 했다. |

## 변경 파일과 확인 기록

- 화면 구성, 입력 상태, 판정 결과 표시는 [app.py](../app.py), 색상·간격·버튼 크기·모바일 배치는 [web.css](../web.css)에 있다. 웹 판정은 기존 TV-13 분류기를 사용한다.
- [배포 패키지 생성기](../tools/build_space.py)에 `web.css`를 포함했고, [배포 안내](deploy.md)에 수동 판정 흐름과 파일 목록을 반영했다.
- 개편 때 데스크톱과 390px 모바일 배치를 확인했다. 최종 수정 때 웹 앱 테스트 8개가 통과했고, 브라우저에서 버튼 높이 48px와 판정 전 네 줄을 확인했다. 실제 판정 호출에서도 확률 목록과 위치 지도 응답을 확인했다. [협업 노트](codex_handoff.md)
