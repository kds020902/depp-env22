**공통화 전후 비교 방법**
1. 리팩터링 전 코드를 같은 기계에서 두 번 돌려 자기 재현성부터 확인하고, 커밋된 manifest와도 비교한다.
2. 새 코드를 같은 기계·같은 패키지 버전에서 돌린다. `PYTHONHASHSEED`를 고정한 경우와 2~3개 다른 값으로도 돌린다.
3. `manifest.csv`는 바이트 단위로 비교하고(`cmp`), 사진은 상대 경로와 sha256 목록을 정렬해 `diff`한다.
4. 1에서 커밋본과 다르면 기준을 "같은 기계의 옛 코드 출력"으로 잡는다. 임계값(0.80/0.85/0.90/0.92) 근처에서 부동소수 차이가 날 수 있기 때문이다. 이때 `S`, `near`, ORB 결과, `dup`, `ses`, `split`을 저장해 단계별로 비교하면 어디서 갈라지는지 보인다.
5. 데이터 없이도 `git show 88c10d9:`의 옛 함수와 새 함수에 같은 무작위 입력을 넣어 배정 결과를 비교할 수 있다.
