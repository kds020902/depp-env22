# 3단계 신선도 판별기 데모 페이지에서 뺀 설명 (2026-11-18)

데모 페이지(claude.ai 아티팩트)에서 지운 소개 문단과 맨 아래 설명을 그대로 보관한다.

## 소개 문단

채소 사진 한 장을 보고 종류와 상태(정상·비정상)를 판별합니다. 비정상일 확률이 50%를 넘으면 비정상, 20~50%면 확인 필요, 20% 이하면 정상으로 표시해서, 일부만 상한 채소를 사람이 한 번 더 보게 합니다. 아래 여덟 가지가 아닌 사진은 "학습된 데이터가 아닙니다"로 표시합니다. 결과 맨 위의 최종 판정은 저장소의 최종 판정(채소 모델 + CLIP 분류기 2개)과 같은 방법이고, 수확·선별 로봇이라면 어떻게 움직일지도 함께 보여 줍니다. 그 아래 빠른 분석은 다섯 채소만 배운 채소 모델의 참고 결과로, 상했다고 본 부분을 사진 위에 빨갛게 칠하고 9군데를 확대해서 다시 봅니다. 사진은 이 브라우저 안에서만 분석되고 어디로도 전송되지 않습니다.

## 맨 아래 설명

확률은 Valid 사진 300장으로 보정(온도 보정)한 값입니다. Test 300장에서 "97% 이상"이라고 답한 199장은 실제로 96.5%가 맞았습니다. 비정상 확률은 다섯 가지 비정상 클래스 확률의 합이고, 20%·50%·90% 기준은 Test가 아닌 Valid·확인용 사진을 보고 정한 예시 값입니다.
확대 검사는 사진을 가로·세로 절반 크기로 9군데(왼쪽·가운데·오른쪽 × 위·가운데·아래) 잘라 각각 분석합니다. 그래서 분석 시간이 약 10배 걸립니다.
"학습된 데이터가 아닙니다"는 모델 출력의 에너지 점수(−logsumexp)가 기준을 넘을 때 표시합니다. 자주 틀리는 경우는 밭에 달린 채 일부만 검게 썩은 토마토를 정상으로 보는 것과, 작은 웹 사진 속 정상 피망을 비정상으로 보는 것입니다.
빨간 표시는 모델의 마지막 특징 지도(7×7칸)에서 "비정상" 점수를 "정상" 점수보다 높인 정도입니다. 일부만 상한 사진 57장에서 가장 진한 칸이 실제로 상한 곳에 떨어진 것은 37장(65%)입니다(이전 버전 39장, 사진 한가운데 칸을 찍으면 27장). 작은 반점의 정확한 위치보다는 대략 어느 쪽인지를 보여 줍니다.
다시 찍기 안내는 이 판정의 확률이 90% 미만일 때 나옵니다. Valid에서 90% 이상인 사진은 97.6%를 맞혔고, 90% 미만은 73%만 맞혔습니다. 사진의 밝기·흐림·크기로도 안내해 보았지만, 경고가 뜬 인터넷 사진이 오히려 더 잘 맞아서 쓰지 않았습니다.
빠른 분석은 채소 모델(EfficientNet-B0, 16MB)만 씁니다. 최종 판정은 저장소의 최종 판정(버전 TV-11)과 같습니다. 채소 모델에 CLIP(ViT-B/16) 위에서 학습한 분류기를 더하고, 이 분류기는 "다섯 채소가 아님"(과일·일상 사진·다른 채소 2,850장)도 배웠습니다. 두 모델의 확률을 합쳐 판정하고, CLIP 분류기가 다섯 채소가 아니라고 보면 거릅니다. 그다음 두 번째 CLIP 분류기(16칸 + "여덟 채소가 아님", 글 설명 점수 섞음)가 양파·고구마·대파로 바꿀지 정합니다. Test 300장 95.7%, 봉인한 새 인터넷 시험지 241장 82.6%(다섯 채소만 쓰면 83.8%)를 맞힙니다(채소 모델만 쓰면 Test 91.3%). TV-11은 상한 사진에 많은 스톡 사진 워터마크를 "상함"의 단서로 쓰지 않도록, 작고 반투명한 가짜 워터마크를 정상·상한 사진에 같은 비율로 넣어 다시 학습했습니다. 학습에 없던 워터마크를 정상 사진에 찍었을 때 "상함"으로 바뀌는 수가 이전 버전의 약 절반 이하로 줄었습니다.
"선별 로봇이라면"은 이 판정을 수확·선별 로봇이 쓴다고 했을 때의 동작 예시입니다. 정상은 상자에 담고, 비정상은 버림 칸으로, 확인 필요·확신이 낮은 것(90% 미만)·대파는 사람 확인 칸으로 보내고, 학습하지 않은 물건은 집지 않고 멈춥니다. 실제 로봇에는 사진 속 채소 하나하나의 위치를 찾는 기능이 더 필요합니다.
최종 판정은 브라우저에서 돌리려고 CLIP 사진 부분의 큰 행렬을 8비트(행마다 배율 하나)로 줄였습니다(약 88MB). 같은 8비트 가중치의 PyTorch와는 판정 점수가 소수점 다섯째 자리까지 같았고, 원래 가중치와 비교하면 새 인터넷 시험지 241장 중 240장, Valid 300장 중 299장에서 같은 판정이었습니다. 양파·고구마·대파 분류기까지 넣은 지금 판정은 PC용 predict.py와 비교해 새 채소 시험지 198장 중 197장, 새 인터넷 시험지 241장 중 240장에서 같았습니다(다른 2장은 새 채소 확률 합이 기준 0.8 바로 위인 0.80~0.81인 사진). 계산은 WebAssembly SIMD로 하고, 기기의 CPU 코어 수에 맞춰 최대 4갈래로 나눕니다. 4000×3000처럼 큰 사진은 긴 변 2048픽셀로 줄인 뒤 분석해서 PC용 predict.py와 조금 다를 수 있습니다.
인터넷 사진으로 학습해서, 직접 찍은 사진에서는 정확도가 다를 수 있습니다. 비정상에는 부패·곰팡이·시듦과 싹 난 감자·양파·고구마가 포함됩니다.
