# Test 세트 300장 (내려받기 전용 브랜치)

채소 신선도 분류 프로젝트의 Test 사진만 따로 모은 브랜치다. 내려받은 뒤에는 지워도 된다. 원본은 메인 저장소의 `dataset/test`다.

- `P_fresh/`: 정상 150장, `N_rotten/`: 비정상 150장
- 오이·감자·토마토·피망·당근 × 정상·비정상, 클래스마다 30장
- `test_list.csv`: 사진마다 정답 클래스, 채소 종류, 정상/비정상, 출처
- `model_predictions.csv`: 현재 모델(model.pth)의 예측과 맞았는지(correct). 275/300장(91.7%)을 맞혔다.
