# 사용자 사진 2차 (상한 고구마, 흙 묻은 정상 감자): 참고용 확인 규칙 (모델에 넣기 전에 작성, 2026-11-23)

## 무엇인가
- 사용자가 구글 이미지 검색에서 직접 모은 사진 60장이다(상한 고구마 30, 흙 묻은 정상 감자 30). 사용자가 "테스트해 보라"고 했다.
- **참고용 확인이다. 채택을 정하는 시험이 아니다.**
    - SP1은 미리 정한 개발 조건을 어겨서 이미 "반영 안 함"이다(`experiments/sweetpotato_photos`). 이 결과로 그 결정을 뒤집지 않는다.
    - 채택을 정하는 블라인드 시험지는 봉인된 T9다. T9는 이번에도 채점하지 않는다.
- 쓰임: TV-12가 T8과 비슷한 사진에서 여전히 같은 실수를 하는지, 사진 추가(SP1)가 이런 사진에서 어느 쪽으로 움직이는지 본다. 다음 실험의 방향을 정하는 데만 쓴다.

## 사진 처리 (`photos.csv`, 모델 답을 보기 전에 정함)
| 처리 | 상한 고구마 | 흙 묻은 감자 | 뜻 |
|---|---:|---:|---|
| 채점 (깨끗한 사진) | 9 | 24 | |
| 채점 (글자·워터마크 표시) | 6 | 2 | 따로 적는다. T8과 같은 방식 |
| 뺌: T9·SP1 학습 사진과 같은 사진 | 5 | 0 | **어떤 모델에도 넣지 않는다** (T9를 지키기 위해) |
| 뺌: T8에 이미 있던 사진 | 2 | 4 | 이미 채점한 사진이라 다시 세지 않는다 |
| 뺌: 라벨이 애매함 | 8 | 0 | 종류나 상한 여부를 사진으로 알기 어렵다 |

- 겹침은 사진끼리의 CLIP 닮음(0.95 이상)과 눈으로 본 것으로 정했다. 작은 미리보기 사진이라 같은 사진도 닮음 값이 낮게 나오는 경우가 있어서, T9와 같은 표본으로 보이는 사진은 값이 낮아도 뺐다.
- 라벨은 사용자가 적은 것을 Claude가 다시 봤고, 판단이 다르면 뺐다(T8과 같은 규칙).

## 한계 (미리 적음)
- **장수가 적다.** 깨끗한 상한 고구마가 9장이라 한 장이 11%포인트다. 퍼센트로 읽지 말고 장수로 읽는다.
- 사진 주소가 구글 미리보기 주소라서 원래 출처를 알 수 없다. 같은 출처 2장까지라는 규칙을 확인할 수 없다.
- 미리보기 크기(대부분 300~700픽셀)의 작은 사진이다. 스톡 사진이 많고 흰 배경에 하나만 놓인 사진이 대부분이다.
- 흙 묻은 감자 중 몇 장은 흙보다 껍질 색(러셋 감자)에 가깝다. 정상 감자라는 라벨은 맞으므로 넣었다.

## 채점
- `python results/user_photos_2/score.py OUT.json`: TV-12와 SP1을 같은 사진으로 한 번 채점한다.
- 맞음의 정의는 T9와 같다(고구마 사진은 고구마로 답하면 맞음, 감자 사진은 클래스까지 맞아야 맞음).
- 볼 숫자: 상한 고구마를 고구마로 답한 수 / 감자로 답한 수, 흙 묻은 감자를 맞힌 수 / 상한 감자로 답한 수 / 고구마로 답한 수, 판단 보류 수. 깨끗한 사진과 전체를 따로 적는다.
