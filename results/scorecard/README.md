# 성적표 (TV-12)

`python results/scorecard/make_scorecard.py results/scorecard/scorecard.json` (작업 폴더 `DEPP_WORK` 필요)

**새로 채점한 것이 아니다.**
- T3·T4는 채점할 때 저장한 답을 썼다.
- Test 300과 새 인터넷 241은 마지막 채점 때 저장한 모델 출력을 썼다. 스크립트가 기록된 합계(285, 188)와 같은지 확인한다.
- 같은 답을 클래스별·오류별로 나눈 것이므로, 블라인드 테스트셋 사용 횟수는 늘지 않는다.

## 다섯 채소 사진

| 시험지 | 어떤 사진 | 쓴 횟수 | 맞게 남김 (95% 구간) | 상함 → 정상 | 정상 → 상함 |
|---|---|---|---:|---:|---:|
| Test 300 | 학습과 같은 출처(Kaggle) | 15번 | 285/300 (95.0%, 92~97%) | 6/150 (4%) | 2/150 (1%) |
| 새 인터넷 241 | Flickr·iNaturalist | 10번 | 188/241 (78.0%, 72~83%) | 16/101 (16%) | 6/140 (4%) |
| **T3** (137장) | iNaturalist·Commons, 처음 본 사진 | 1번 | **109/137 (79.6%, 72~86%)** | 8/38 (21%) | 16/99 (16%) |
| T4 (63장) | 약점을 겨냥해 모은 사진 | 1번 (참고) | 41/63 (65.1%, 53~76%) | 9/23 (39%) | 9/40 (22%) |

**용어**
- 상함 → 정상: 상한 채소를 정상이라고 답함. 먹을 수 있으므로 가장 위험한 오류다.
- 정상 → 상함: 멀쩡한 채소를 버리게 되는 오류다.

**클래스별로 약한 곳**
- T3: 정상 감자 10/20(흙 묻은 감자를 상했다고 봄), 상한 토마토 9/15
- 새 인터넷 241: 상한 토마토 48/74, 상한 피망 2/7
