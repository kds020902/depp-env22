# 초기 모델부터 지금까지 같은 사진으로 비교

프로젝트를 진행하며 바꾼 시스템들을 같은 시험지로 채점했다(`compare.json`). 비교용 채점이라 어느 모델도 이 숫자로 고르지 않았다.

## 비교한 시스템

| 이름 | 구성 | "학습된 데이터가 아닙니다" |
|---|---|---|
| **초기 모델** | ResNet18, 마지막 층만 학습(5,130개 파라미터), 데이터 증강 없음 | 없음 |
| **개선 1** | EfficientNet-B0 전체 미세조정, 데이터 증강, 확률 보정 (데모의 빠른 분석) | 채소 모델 energy 점수 |
| **개선 2** | 개선 1 + CLIP 분류기(10클래스) 접목 ([clip_classifier](../../../experiments/clip_classifier/README.md)) | 두 모델 중 하나라도 거르면 거름 |
| **지금** | 개선 2 + "다섯 채소가 아님" 학습([not_five_class](../../../experiments/not_five_class/README.md)) + CLIP 기준으로만 거르기([clip_only_reject](../../../experiments/clip_only_reject/README.md)) | CLIP "다섯 채소가 아님" |
| 후보 F1 | 지금 + 농가 토마토·상한 과일 학습([fruit_farm_tomato](../../../experiments/fruit_farm_tomato/README.md)), 채택 안 함 | CLIP "다섯 채소가 아님" |

- **초기 모델은 다시 학습했다.** 1차 모델은 6클래스(오이·감자·토마토)였다.
    - 그래서 같은 방법(ResNet18 마지막 층만, lr 0.005, 증강 없음, seed 42)으로 지금 Train 1,260장의 10클래스를 다시 학습했다(`initial_recipe_10class/`).
    - Valid로 4번째 epoch를 골랐다.
    - 원래 1차 방식의 6클래스 모델은 Test 180장에서 87.2%였다.
- 개선 1·2와 지금은 같은 채소 모델 가중치를 쓴다. 개선 2의 CLIP 분류기는 그때 저장한 가중치다.

## 단계별로 좋아진 것

- **초기 → 개선 1 (모델 교체):**
    - 같은 출처 Test가 15장 올랐다.
    - 휴대폰·밭 사진(160장)이 75.6%에서 92.5%로 가장 크게 올랐다.
    - 초기 모델은 거르는 기능이 없어서, 과일·일상 사진에도 늘 채소 이름을 붙인다.
- **개선 1 → 개선 2 (CLIP 접목):**
    - 처음 보는 인터넷 사진이 71.0%에서 79.3%로 올랐다.
    - 과일 거르기는 27%에서 65%가 됐다.
    - 대신 진짜 채소를 46장(19%) 걸렀다.
- **개선 2 → 지금:**
    - 잘못 거른 진짜 채소가 46장에서 14장으로 줄었다.
    - 과일 거르기는 90%, 일상 사진은 100%가 됐다.
    - 새 시험지의 상한 토마토는 44장에서 55장으로 늘었다.
- **예외: 상한 과일 거르기는 개선 2가 지금보다 낫다**("아무 사진"의 상한 과일 50장 중 34 대 24).
    - 개선 2는 채소 모델 기준으로도 함께 걸렀다.
    - 지금은 진짜 채소를 덜 거르려고 그 기준을 뺐다.

## 주의

- Test는 여러 후보를 고르는 데 여러 번 쓰였다(지금까지 8번).
- 처음 보는 사진의 실력은 새 인터넷 시험지와 "아무 사진" 시험지로 보는 것이 더 정확하다.
- `compare.py`는 작업 폴더의 경로를 그대로 담고 있어서 기록용이다.
