# 확률 보정과 학습하지 않은 사진 거르기

`model.pth`에 들어 있는 확률 보정(`calibration`)과 "학습된 데이터가 아닙니다" 판정 기준(`unknown_check`)을 어떻게 정하고 채점했는지 적은 기록이다. 값을 만드는 코드는 `src/model_utils.py`의 `calibration_extras`이고, 이 폴더의 `evaluate.py`로 아래 숫자를 다시 낼 수 있다(`results.json`).

## 순서

1. 온도 T와 거르기 기준은 Valid 300장으로만 정했다.
2. 거르는 방법 6가지는 Valid와 바깥 사진의 개발용 절반(과일 200장, 일상 사진 200장)으로 비교해 하나를 골랐다.
3. 고른 뒤 바깥 사진의 채점용 절반과 Test 300장을 한 번만 채점했다.

## 바깥 사진

- **과일 400장:** 채소와 같은 Kaggle 데이터([Fruits and Vegetables Dataset](https://www.kaggle.com/datasets/muhriddinmuxiddinov/fruits-and-vegetables-dataset), CC0)의 `Fruits` 폴더에서 10종(사과·바나나·망고·오렌지·딸기 × 정상·상함)마다 40장씩 무작위로 뽑았다. 학습에 쓰지 않은 폴더다.
- **일상 사진 400장:** COCO val2017에서 음식(바나나·사과·브로콜리·당근 등)과 그릇·식탁이 없는 사진 중 무작위로 뽑았다. 사람·동물·탈것·실내 사진이 많다.
- `outside_photos.csv`에 사진마다 출처와 개발용(`dev`)/채점용(`test`) 구분을 적었다. 사진 파일은 올리지 않았다. `evaluate.py fetch`가 Kaggle 압축 파일과 COCO 주소에서 같은 사진을 다시 모은다.

## 확률 보정

학습 때 label smoothing(0.1)을 써서 원래 softmax 점수는 실제 정답률보다 낮게 나왔다. 점수(logit)를 온도 T로 나눈 뒤 softmax를 하는 온도 보정을 Valid의 cross-entropy가 가장 낮아지게 맞췄다. T=0.528이다. 1등 클래스는 바뀌지 않으므로 정확도는 그대로다.

| | 보정 전 | 보정 후 |
|---|---:|---:|
| Valid ECE | 0.146 | 0.040 |
| Test ECE | 0.132 | 0.038 |
| Test 평균 확률 (정확도 91.7%) | 78.5% | 93.4% |

ECE는 확률을 15구간으로 나눠 구간마다 "평균 확률과 실제 정답률의 차이"를 사진 수로 가중 평균한 값이다. 작을수록 확률을 믿을 만하다.

보정 후 Test 300장을 확률 구간별로 나누면 다음과 같다.

| 확률 | 사진 수 | 실제 정답률 |
|---|---:|---:|
| 50% 미만 | 3 | 33% |
| 50–70% | 23 | 65% |
| 70–90% | 29 | 79% |
| 90–97% | 37 | 92% |
| 97% 이상 | 208 | 97% |

## 학습하지 않은 사진 거르기

각 사진의 점수를 계산해 기준보다 크면 10개 클래스 중 하나로 답하지 않고 "학습된 데이터가 아닙니다"라고 답한다.

개발용 절반으로 비교한 방법별 AUROC(1에 가까울수록 채소 사진과 바깥 사진을 잘 가른다)는 다음과 같다.

| 방법 | 점수 | AUROC |
|---|---|---:|
| 최고 확률 (MSP) | −(보정된 최고 확률) | 0.905 |
| **energy** | −logsumexp(logit) | **0.950** |
| 최근접 Train 사진 (k=1, 5, 10) | 1 − (k번째로 가까운 Train 사진과의 코사인 유사도) | 0.944, 0.936, 0.937 |
| Mahalanobis 거리 | 클래스 평균까지의 거리 중 최솟값 | 0.928 |

energy를 골랐다. 기준은 Valid 채소 사진 300장 중 95%(285장)가 통과하는 값(−2.283)이다.

채점용 절반과 Test의 결과는 다음과 같다.

| 사진 | 거른 수 |
|---|---:|
| 일상 사진 (COCO) | 192/200 (96%) |
| 과일 사진 | 112/200 (56%) |
| Test 채소 사진 (잘못 거른 것) | 10/300 (3.3%) |

- Test에서 거른 10장은 상한 피망 4장, 상한 오이·상한 감자·정상 토마토 각 2장이다. 그중 3장은 원래 틀리게 답한 사진이었다. 거르지 않은 290장의 정확도는 92.4%다.
- 과일 종류별로 거르지 못하고 통과한 수는 정상 사과 17/22, 정상 오렌지 15/17, 정상 망고 9/19, 상한 사과 10/19, 상한 망고 10/21, 상한 딸기 8/17, 정상 딸기 6/23, 상한 바나나 5/21, 상한 오렌지 5/20, 정상 바나나 3/21이다. 둥글고 매끈한 과일(사과·오렌지)은 토마토·피망과 비슷해 보여 대부분 통과한다.

## 한계

- 걸러야 할 사진을 학습에 넣지 않고 출력 점수만 본다. 과일·다른 채소 사진을 "그 밖" 클래스로 함께 학습하면 더 잘 거를 수 있지만, 다시 학습해야 한다.
- 바깥 사진은 과일 5종과 COCO뿐이다. 양파·가지처럼 다른 채소 사진은 시험하지 않았다.
- Valid의 95%를 통과시키는 기준이라 진짜 채소 사진도 몇 %는 거른다.
