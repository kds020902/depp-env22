# 인터넷에 올라온 사진으로 평가

Test 300장은 학습 데이터와 같은 Kaggle 데이터에서 나눈 사진이다. 처음 보는 출처의 사진에서도 맞히는지 보려고, 사람들이 Flickr와 Wikimedia Commons에 올린 사진 221장으로 현재 모델(`model.pth`)을 채점했다. 이 사진은 학습에도, 설정을 고르는 데에도 쓰지 않았다.

## 사진 모으기

1. 공개 라이선스 사진 검색(Openverse, Wikimedia Commons)에서 클래스마다 영어 검색어 3~7개로 찾았다(예: "rotten tomato", "sprouting potato", "moldy carrot"). 상한 사진이 적은 클래스는 검색어를 더 넣어 한 번 더 찾았다.
2. 받은 1,249장 중 3차 데이터 1,860장과 같은 사진(복사본 검사, 3차와 같은 규칙)과 서로 겹치는 사진을 뺐다.
3. 남은 1,166장을 한 장씩 눈으로 보고, 실제 채소 사진이면서 종류와 정상·상함이 분명한 사진만 남겼다. 영화 사이트 "Rotten Tomatoes" 관련 사진, 동물, 그림·도표, 요리, 여러 채소가 섞인 사진, 고추는 뺐다.
4. **정답은 모델을 돌리기 전에 정했다.** 모델이 틀린 사진을 빼거나 바꾸지 않았다.

사진마다 출처, 라이선스, 원래 페이지는 `outside_test.csv`에 있다(Flickr 138장, Wikimedia Commons 83장). 사진 파일은 라이선스가 제각각이라 올리지 않았다. `evaluate.py fetch`로 같은 사진을 다시 받는다.

| 클래스 | 사진 수 | 현재 모델이 맞힌 수 |
|---|---:|---:|
| 오이 정상 / 상함 | 12 / 2 | 12 / 2 |
| 감자 정상 / 상함 | 16 / 42 | 12 / 32 |
| 토마토 정상 / 상함 | 49 / 45 | 47 / **17** |
| 피망 정상 / 상함 | 22 / 2 | 15 / 2 |
| 당근 정상 / 상함 | 28 / 3 | 25 / 3 |
| **합계** | **221** | **167 (75.6%)** |

- 채소 종류만 보면 198장(89.6%), 정상·상함만 보면 186장(84.2%)을 맞혔다.
- 시드만 바꿔 학습한 모델(S7)은 162장(73.3%)이었다.
- **가장 큰 약점은 상한 토마토다(45장 중 17장).** 17장을 정상 토마토로, 6장을 상한 감자로 봤다. 인터넷의 상한 토마토 사진은 밭에 달린 채 아랫부분이 검게 썩은 토마토(배꼽썩음병), 덜 익은 초록 토마토, 흰 곰팡이가 핀 토마토가 많은데, 학습 데이터에는 이런 사진이 적다.
- 상한 오이·피망·당근은 공개 라이선스 사진이 2~3장뿐이라 판단할 수 없다.

## 한계

- 사람이 골라서 올린 사진이라 실제로 마트나 부엌에서 찍은 사진과는 다르다. 외국 채소가 대부분이다.
- 클래스마다 사진 수가 많이 다르다(2~49장). 합계 점수는 토마토·감자 비중이 크다.

## 다시 돌리기

```bash
python results/10class/outside_test/evaluate.py fetch --photos outside_photos
python results/10class/outside_test/evaluate.py run --photos outside_photos --model model.pth
```

`results.json`은 현재 모델의 결과다. 사진이 원래 페이지에서 지워지면 받은 사진 수가 221장보다 적을 수 있다.
