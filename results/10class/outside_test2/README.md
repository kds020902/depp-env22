# 새 인터넷 시험지 (241장, 봉인)

[첫 인터넷 시험지 221장](../outside_test/README.md)은 여러 실험에서 여러 번 봤다. 그래서 개발용으로 돌리고, 마지막 판단에 쓸 시험지를 새로 만들었다. 이 사진은 학습에도, 설정을 고르는 데에도 쓰지 않았다.

## 만들기

1. **정상 사진:** Openverse(Flickr 등)에서 클래스마다 영어 검색어 4~6개로 찾았다. 예전에 한 번이라도 검색된 사진은 뺐다.
2. **상한 사진:** 공개 사진이 적어서 iNaturalist에서도 찾았다. 일반인이 올린 부패·곰팡이 관찰 기록이다. 곰팡이 이름(Botrytis, Rhizopus 등) + 채소 이름, 또는 채소 이름 + rot/mold/sprout로 찾았다. 관찰 1건당 1장만 넣었다.
3. **겹침 제거:** 예전 사진과 CLIP 특징 코사인 0.95 이상인 사진은 뺐다. 예전 사진은 3차 데이터, 인터넷 221장, 160장 시험지, 아시아 오이, 과일·일상 확인 사진 등이다.
4. **올린 사람 분리:** Openverse 사진은 올린 사람 단위로 시험지 쪽과 학습 후보 쪽을 나눴다(해시의 홀짝). 첫 인터넷 시험지에 사진을 올린 사람은 시험지 쪽에만 둔다.
5. **눈 검수:** 한 장씩 눈으로 보고, 실제 채소 사진이면서 종류와 정상·상함이 분명한 사진만 남겼다. 첫 시험지와 같은 규칙으로 요리, 그림, 여러 채소, 고추, 잎만 보이는 병든 식물, 현미경·배양 사진은 뺐다. 정상 사진은 무작위 순서(id의 sha1)로 보다가 약 40장이 모이면 멈췄다.
6. **정답은 모델을 돌리기 전에 정했다.** 파일 SHA-256은 `81e52bdadf23a39f36b8e9a9af471063556735100a0f2fb0a03ef66d8393a021`이다.

- 출처는 Openverse 146장(Flickr 143, rawpixel 3)과 iNaturalist 95장이다.
