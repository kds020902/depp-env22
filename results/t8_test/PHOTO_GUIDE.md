# T8 사진 모으기 안내 (사용자용)

이 폴더는 새 블라인드 시험지 **T8**에 넣을 사진을 모으는 곳입니다.
규칙 전체는 저장소의 `results/t8_test/RULES.md`에 있습니다(덧붙임 1이 이 안내의 근거).

## 왜 모으나
- 지금 모델(TV-12)이 실제로 얼마나 잘하는지, 특히 **상한 채소를 놓치지 않는지** 공정하게 재려고 모읍니다.
- 이전 시험지 T3~T7은 정답을 이미 봐서 다시 쓰지 않습니다(컨닝 방지).
- 상한 채소 사진은 인터넷 공개 사진 사이트(iNaturalist)에 거의 없습니다. 그리고 이 작업 환경에서는 Flickr·Wikimedia가 막혀 있습니다. 그래서 사람이 웹에서 직접 골라 줘야 합니다.

## 꼭 지킬 것 (공정한 시험지가 되려면)
1. 검색어를 하나 정하고, **검색 결과에서 조건에 맞는 사진을 위에서부터 차례대로** 담습니다.
    - 모델이 틀릴 것 같은 사진이나 맞힐 것 같은 사진을 골라 담지 않습니다.
2. 고른 사진은 **데모나 모델에 넣어 보지 않습니다.**
3. 같은 사이트·같은 사람 사진은 **클래스마다 2장까지**입니다.
4. **넣지 않는 사진:**
    - 밭·화분에서 자라는 것, 줄기에 달린 열매
    - 자르거나 요리한 것
    - 무엇인지 애매한 것, 여러 채소가 반반 섞인 것
    - 워터마크·스톡 사진(셔터스톡·게티·알라미 등 글씨가 박힌 것)

## 상한 사진의 비율
- 상한 클래스마다 **"척 봐도 썩은 것" 반, "약간 썩은 것" 반**을 담습니다.
    - **약간:** 곰팡이·무른 곳·썩은 반점이 보이는 면의 약 1/4 미만
    - **척 봐도:** 그 이상이거나 전체가 무른 것
- 차례대로 담다가 한쪽이 목표에 차면, 그쪽 사진은 건너뛰고 다른 쪽만 계속 담습니다.
- 싹만 난 감자·양파·고구마는 "싹"으로 적고, 상한 클래스의 1/3까지만 넣습니다.

## 파일 이름 규칙

```
채소_상태_세부_번호.확장자
```

| 칸 | 쓰는 말 |
|---|---|
| 채소 | `감자` `토마토` `오이` `피망` `당근` `양파` `고구마` `대파` `과일` `다른채소` |
| 상태 | `정상` 또는 `상함` (과일은 `곰팡이`) |
| 세부 | 정상이면 `깨끗` 또는 `흙묻음`, 상함이면 `척봐도` · `약간` · `싹` 중 하나 |
| 번호 | `01`부터 두 자리. **검색 결과에서 담은 순서대로** 붙입니다(중간에 건너뛴 사진은 번호를 주지 않습니다) |

- 띄어쓰기 대신 밑줄(`_`)을 씁니다. 확장자는 원래 것 그대로(`.jpg`, `.png`, `.webp`) 둡니다.
- 한 클래스에서 검색어를 바꿔도 번호는 이어서 붙입니다.

**예시**

| 파일 이름 | 뜻 |
|---|---|
| `오이_상함_약간_01.jpg` | 상한 오이, 살짝 상함, 첫 번째로 담은 사진 |
| `오이_상함_척봐도_02.jpg` | 상한 오이, 척 봐도 썩음, 두 번째 |
| `피망_상함_약간_07.png` | 상한 피망, 살짝, 일곱 번째 |
| `토마토_상함_척봐도_03.jpg` | 줄기에서 딴 토마토, 척 봐도 썩음 |
| `감자_정상_흙묻음_01.jpg` | 흙 묻은 멀쩡한 감자 |
| `감자_상함_싹_05.jpg` | 싹만 난 감자 |
| `양파_상함_약간_02.webp` | 살짝 상한 양파 |
| `과일_곰팡이_척봐도_04.jpg` | 곰팡이가 많이 핀 과일 |
| `과일_곰팡이_약간_09.jpg` | 곰팡이가 살짝 핀 과일 |

## 함께 적어 주실 것: `목록.txt`
- 폴더마다 하나씩 두고, 사진 한 장에 한 줄을 적습니다. 정답은 파일 이름에 들어 있으니 따로 적지 않아도 됩니다.
- **원래 주소**는 사진이 있던 웹페이지 주소입니다. 구글 이미지라면 사진을 눌러 연 "방문" 페이지 주소를 적습니다.

```
파일이름 | 원래 주소 | 검색어 | 메모(선택)
오이_상함_약간_01.jpg | https://example.com/rotten-cucumber-photo | 썩은 오이 |
오이_상함_척봐도_02.jpg | https://blog.example.kr/post/123 | 썩은 오이 | 곰팡이 흰색
오이_상함_약간_03.jpg | https://forum.example.com/t/456 | rotten cucumber | 검색어 바꿈
```

- 메모에는 애매했던 점이나 건너뛴 이유를 자유롭게 적습니다. 비워 둬도 됩니다.
