- **만든 방법:**
    - 사진을 모을 때마다 올린 사람 단위로 시험지 쪽을 나눴다. 기존 봉인 시험지에 사진을 올린 사람은 시험지 쪽이다.
    - 회차마다 새로 시험지로 가는 사진은 클래스마다 1/3까지다.
    - 같은 사람이 올린 사진은 학습에 쓰지 않는다.
- **채점 횟수:**
    - 시험지 1: 3번 (V4-R, V5-H·R5, V6-H·V6-A)
    - 시험지 2: 2번 (V5-H·R5, V6-H·V6-A)
    - 시험지 3: 1번 (V6-H·V6-A)
- **좋은 답:** 종류를 맞히고 거르지 않은 것이다. 정상/비정상까지 맞힌 수는 따로 적는다.
- **파일:**
    - `new_veg_test.csv`의 SHA-256은 `b9baad1f24e4911464028560a1acfdd622debad7c5f4355e9858f0d83d7267b3`이다.
    - 열: `id`, `test`(1·2·3), `class_name`, 출처, 라이선스, 올린 사람, 원래 페이지, 받은 주소
- **사진 파일은 라이선스가 제각각이라 올리지 않았다.**
    - Openverse·iNaturalist·위키미디어 사진은 `image_url`에서 받을 수 있다.
