# 시험지 T3 (인터넷 공개 사진 247장, 정답 고정 뒤 한 번 채점)

직접 찍은 사진이 없어서, 사람들이 인터넷에 올린 공개 사진으로 **처음 보는 시험지**를 새로 만들었다. 만드는 규칙과 채점 계획은 사진을 모으기 전에 [RULES.md](RULES.md)에 적었다. 정답 목록 `t3_test.csv`의 SHA-256도 모델을 돌리기 전에 그 파일 끝에 적고 커밋했다(1cf8d93).

- **출처:** iNaturalist 201장, Wikimedia Commons 46장
- **예전과 겹치지 않음:**
    - 예전 수집에서 검색된 사진과, 예전에 사진을 올린 사람의 사진은 처음부터 뺐다.
    - 예전 사진 37,405장과의 CLIP 코사인은 모두 0.943 이하다.
- **모자란 클래스:** 상한 오이·파프리카·당근은 1장씩, 상한 고구마는 0장이다. 이 네 클래스는 이 시험지로 말할 수 없다.
- 사진 파일은 라이선스가 제각각이라 올리지 않았다. 원래 페이지·라이선스·작가는 `t3_test.csv`에 있다.

## 알게 된 것

1. **처음 보는 인터넷 사진에서는 Test(95.7%)보다 훨씬 낮다.**
    - 다섯 채소 맞게 남김은 78.8%다. 종류는 거의 다 맞히지만(97.8%) 정상·상함을 많이 틀린다.
2. **흙 묻은 정상 감자를 상한 감자로 본다(9/20).**
    - iNaturalist의 정상 감자 사진은 갓 캔, 흙이 묻은 감자가 많다.
    - 정상 당근 3장도 같은 이유로 틀렸다. 학습 데이터에서 "흙 = 상함" 지름길이 남아 있는 것으로 보인다.
3. **곰팡이 핀 과일을 상한 감자로 본다(14/30).**
    - ZS8이 일부(5장)를 더 거르지만, 상한 과일 거르기는 여전히 약하다(13/30).
4. 상한 토마토의 초기 증상(작은 반점, 배꼽썩음)은 정상으로 본다(5/15).
5. 정상 고구마 3장을 감자로 본다. 껍질이 연한 고구마다.
