# 시험지 T6 (블라인드 테스트셋 175장, 정답 고정 뒤 한 번 채점)

- **만든 이유:** TV-12의 되풀이되는 약점 세 가지를 고치는 후보를 마지막에 공정하게 재려고 만들었다([RULES.md](RULES.md)).
    - 약점 1: 정상 감자 → 상한 감자
    - 약점 2: 상한 과일 → 상한 감자
    - 약점 3: 상한 토마토 → 정상 토마토
- **사용 횟수: 1번.** 2026-11-04에 TV-12와 후보 G1C1을 한 번씩 채점했다(`score.py` → [scores_once.json](scores_once.json)).
    - G1C1 = 대파 없앰([no_greenonion](../../experiments/no_greenonion/README.md)) + 토마토 조각 검사 t 0.9([tomato_crops](../../experiments/tomato_crops/README.md))
- **채점한 장 수:** 174장. 대파 사진 1장은 Flickr가 이 컨테이너를 막아 받지 못했다. 그래서 두 모델 모두에서 뺐다(RULES.md 덧붙임, 채점 전에 적음).

| T6 | TV-12 | G1C1 | 조건 |
|---|---:|---:|---|
| 상한 토마토 22 | 22 (100%) | 22 | +3 ❌ |
| 정상 토마토 20 | 19 (95%) | 19 | −1 이내 ✅ |
| 다섯 채소 맞게 남김 97 | 83 (85.6%) | 83 | TV-12 이상 ✅ |
| 걸러야 할 사진 75 거름 | 57 (76%) | 53 | −3 이내 ❌ |
| 양파 2 종류 | 2 | 2 | −1 이내 ✅ |
| 정상 감자 29 (약점 1) | 18 (62%) | 18 | 참고 |
| 상한 과일 40 거름 (약점 2) | 23 (58%) | 20 | 참고 |

- **결과:** 반영 조건을 통과하지 못했다. TV-12를 그대로 쓴다.
- **바뀐 답 5장은 모두 대파를 없앤 새 채소 분류기 때문이다.**
    - TV-12가 거른 썩은 과일 3장, 다른 채소 1장, 정상 감자 1장이 "상한 양파·상한 고구마"로 답해졌다.
    - 토마토 조각 검사로 바뀐 답은 없다.
- **한계:**
    - 상한 토마토 22장 중 21장은 많이 썩은 데이터셋 사진이다. TV-12가 이미 모두 맞혀서 "살짝 상한 토마토"의 개선은 이 시험지로 잴 수 없었다.
    - 상한 감자는 5장, 피망은 4장, 새 채소는 2장뿐이다.
